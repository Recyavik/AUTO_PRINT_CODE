# Суфлёр и «Эфир» 0.9 — доработка после первого живого урока

## Зачем

Пользователь поставил 0.8.0 и прошёл по нему как по уроку. Нашлось много неудобств и логических ошибок:
«нужно переписать и сделать адекватно». Цель 0.9 — чтобы суфлёр, «Эфир» и редактор занятий вели себя
предсказуемо на живом уроке и выглядели так, чтобы с одного взгляда было ясно, что читать вслух, а что нет.
Пользователь отдал решения нам («подумай и предложи решение, и реши, как нужно»); вопросов не задаём.

## Что сказал пользователь → что делаем

| Сказал | Решение |
|---|---|
| «Нажал светлая тема — завис» | Причина найдена: `app.setStyleSheet` перерисовывает оформление каждого виджета всех открытых вкладок (~1 мс на виджет, на данных пользователя 6–20 с). Держим живым только текущее занятие (+ предыдущее), при смене темы вкладки собираются заново, шапка блока легче (меньше виджетов). Курсор «занят» на время смены. |
| «Навожусь на минуты/список и прокручиваю — меняется, я даже не кликнул» | Во всей программе: колёсико над счётчиком, выпадающим списком, ползунком без фокуса крутит страницу, а не значение. |
| «При закрытии сворачивать в трей», «суфлёр не связан с автопринт» | «Закрыть» по умолчанию прячет в трей (один раз переключаем и тем, у кого было «выкл»). Суфлёр — одно окно Edge со своим профилем: повторное нажатие поднимает его, при выходе из программы оно закрывается. Значок окна и шапка страницы — логотип AutoPrintCode. |
| «Логотип поменяй обратно» | В шапке программы — фирменный знак (плитка с янтарными строками) в обеих темах; страница суфлёра и вкладка эфира — тот же знак (favicon). |
| Время старта привязано к шаблону, а «я захожу и выставляю начало» | В шаблоне «Эфира» поля «Старт» больше нет. «Запустить» спрашивает начало: «Сейчас» или время (быстрые кнопки ближайших :00/:30, поле ЧЧ:ММ, подставлено прошлое время этого шаблона). До начала таймер считает «до начала», потом идёт по расписанию, потом «завершён». В таймере — «Изменить начало…». Урок в суфлёре — так же: «Начать сейчас» или «в ЧЧ:ММ». |
| Тип блока «зарядка» у «Приветствия», «Слайдов», список «так себе» | Это колёсико (см. выше). Вместо двух широких списков в строке расписания — две маленькие кнопки-значка: вид (обычный/перерыв/зарядка — меню) и демонстрация (вкл/выкл/не важно — меню). |
| «Итого — сверху» | Над строками расписания: «Всего 1 ч 30 мин · 13 блоков». Время в строках — от начала («0:00», «0:05»), раз старт не в шаблоне. |
| Зарядки: добавлять несколько за раз | «Добавить видео…» — выбор нескольких файлов. |
| Перерыв: надпись нужна или нет, отсчёт — к надписи, зачем длительность | Раздел «Перерыв»: «По умолчанию N мин (меняется при запуске)», фон; блок «Надпись»: переключатель «Показывать надпись» + текст, «Обратный отсчёт», «Когда время вышло», шрифт, цвет. Кнопка «Предпросмотр» открывает экран перерыва с текущими (несохранёнными) настройками. «Посмотреть вживую» у фона → «Галерея фонов». |
| Таймер шире — текст мелкий; «два до, два после, активную подсветить» | Список в таймере — не больше 5 строк: два до, текущий (подсвечен), два после, с пометками «ещё N раньше/дальше»; строки растут с окном. Широкое низкое окно — повестка полосой по горизонтали из тех же 5 блоков. |
| Вкладку эфира закрыл случайно — открыть напрямую | В таймере, когда вкладка не открыта, на плашке кнопка «Открыть вкладку». |
| Кнопка «Эфир» сверху — другой стиль и больше панели | Такая же плоская кнопка, как «Настройки»: значок + короткий текст; цвет по состоянию: обычный — нет эфира, жёлтый — до начала / перерыв / зарядка, красный — эфир идёт. |
| Уведомление про звук видно ученикам | С экрана эфира убрана плашка «Щёлкните по странице…»; о звуке говорит только таймер. |
| Картинка в редакторе маленькая, в суфлёре нормальная | В редакторе картинка во всю ширину блока (пропорции сохраняются, высота до 520 px), щелчок — окно с картинкой в натуральную величину. |
| «Картинка — это что? Можно, чтобы не отображалось» | У картинки и этапа нет выбора роли слева (картинка — картинка, этап — этап). |
| Роли: в PDF синий/зелёный фон — лучше читается | Суфлёр как PDF: у каждой роли плашка — лёгкий фон своего цвета, полоса слева, сверху маленькая надпись капителью со значком («ГОВОРИШЬ · ПОВТОРЕНИЕ»). «Говоришь» — крупнее и ярче, «Делаешь» — серая и мельче, «Для быстрых» — пунктир (можно пропустить), «Важно» — красная. В редакторе — тот же цвет: фон блока подкрашен ролью, слева — цветная плашка роли с названием (это и кнопка смены роли). |
| «Сделай примеры прям, с картинками, со всем» | Встроенный пример урока «Пример урока: тёмная тема на сайте» — 2 части, этапы с минутами, перерыв, зарядка, все роли, код CSS/JS/HTML, 3 картинки (лежат в программе). Добавляется один раз. |
| «От Юпитера к обычному MD-файлу» | Решение: файл урока — Markdown. «Сохранить урок в .md» кладёт рядом папку с картинками; открывается в любом редакторе, картинки видны. Импорт .md понимает этапы, роли, картинки. Jupyter остаётся для тетрадки учеников и импорта тетрадок; в .ipynb картинки теперь внутри (вложения) — Jupyter их показывает. Внутренняя база программы не меняется. |
| «Остальную часть по Юпитеру доделать» | Картинка печатается в Jupyter: активный блок-картинка + хоткей → картинка в буфер обмена и Ctrl+V в окно (markdown-ячейка Jupyter/VS Code делает из неё вложение). |

## Формат урока в Markdown

```markdown
---
title: Тёмная тема на сайте
---

Вступление до первого этапа (цель урока) — обычный Markdown.

# Часть 1. Тёмная тема                ← раздел (part) для следующих этапов

## Приветствие · 5 мин                 ← этап: название · минуты [· перерыв|зарядка]
*теория*                               ← пометка этапа (одна строка курсивом сразу под заголовком)

> [!say] Повторение                    ← блок с ролью: [!роль] + необязательный заголовок
> Здравствуйте! На прошлом занятии…

> [!ask]
> Какие темы вы предпочитаете?
> → пишут в чат

```css title="Тёмная тема"            ← блок кода (заголовок — необязателен)
.darkTheme { color: #fff; }
```

![Сайт в тёмной теме](Тёмная тема_files/img-ab12.png)   ← блок-картинка (подпись — alt)
```

Роли по-английски в `[!…]` (say, tell, ask, do, important, show, trap, extra, task, explain, hint, text); русские
названия тоже понимаются (`[!говоришь]`). Блок без роли — обычный текст. Неизвестное — как текст, без ошибок.

## Не цели

- Внутренняя база (templates.json) не меняется на .md.
- Суфлёр не переезжает в окно Qt (нет QtWebEngine — +150 МБ).
- Нейросеть продолжает отвечать JSON (путь проверен); .md — для человека и обмена.

## Ограничения

- Все тексты — по-русски; старые данные читаются без потерь (новые поля — по умолчанию).
- Тесты невидимы (offscreen, tests/quiet.py, своя папка данных), никаких окон/трея/браузера на экране.
- Не трогать установленную копию и данные пользователя; GUI не запускать без вопроса.
- Версия 0.9.0.
