# «Эфир» — таймер вебинара и экран эфира в AutoPrintCode

Дата: 2026-11-23. Решения пользователя — из разговора; «моё решение» — выбор исполнителя.

## Зачем

Виктор (автор исходного AutoPrintCode) ушёл из проекта. Его «Таймер вебинара» — отдельная программа со своим
стилем, и вместе с AutoPrintCode это выглядит как несколько разных приложений. Пользователю нужно одно приложение
в его стиле — «суфлёр для ведения урока», где «Эфир» — отдельное дополнение: расписание вебинара, таймер для
себя и экран для учеников с фоном, зарядкой и перерывом.

## Что видит ученик — вкладка браузера «Экран эфира»

- Всегда открыта в браузере, преподаватель захватывает её в демонстрации (вкладка передаётся со звуком).
- Три состояния, больше ничего: **фон** (он же занавес/заглушка), **зарядка** (видео со звуком; доиграло —
  снова фон), **перерыв** (заставка с красивым обратным отсчётом или без него; по окончании — «ПРОДОЛЖАЕМ»,
  убирается кнопкой).
- Фон: чёрный по умолчанию; однотонный цвет; картинка; встроенные анимации в духе старых заставок Windows
  (огоньки, пузыри, куб, звёзды, трубы, градиент, сияние). Выбор с живым предпросмотром — страница-галерея
  в браузере (моё решение: анимации живут в браузере, дублировать их в Qt незачем).
- Нейтрально: ни логотипов, ни фиолетового по умолчанию (бывают разные «провайдеры»).
- Браузер не даёт видео звучать без щелчка по странице: один щелчок по вкладке в начале — дальше всё само.

## Что видит преподаватель

- Кнопка-плашка «Эфир» вверху главного окна AutoPrintCode (и пункт в трее) открывает окно «Эфир»: шаблоны
  вебинаров, «Новый», импорт/экспорт JSON, «Для нейросети» (промпт + пример JSON в буфер).
- Шаблон = пресет: при создании задаётся всё — название, время старта, блоки расписания, фон, зарядки (0…n;
  нет зарядок — нет кнопки), перерыв (минуты, отсчёт да/нет, фон, шрифт, цвет, надписи).
- «Запустить» → плавающее окно таймера в духе HTML-«Повестки эфира»: узкая шапка с «Закрепить» (поверх всех
  окон, видно нажатым), «Свернуть», «Закрыть» (только с подтверждением). Размер — от крошечного (~150×90:
  текущий этап и сколько осталось) до полного с повесткой; текст масштабируется сам. Кнопки эфира — плашкой
  сверху: Фон, Зарядка ▾, Перерыв (показывает минуты из шаблона, можно поправить и начать; во время
  перерыва −1/+1 мин, пауза, убрать).
- Время — по часам от времени старта (как в HTML-повестке); «Сдвинуть на сейчас» и двойной щелчок по блоку
  повестки («начать с него») пересчитывают старт (моё решение: пользователь не сказал, чем плохо время
  у Виктора; это поведение он одобрил как запасное).
- Напоминаний-карточек нет (пользователь: «напоминание такое себе»), роль напоминания — маленький таймер.

## Перенос из «Таймера вебинара»

Его шаблоны (формат совместим с HTML-повесткой: start + schedule[name, demo, min]), видео гимнастики, фон
и шрифт Furore переносятся в Эфир (кнопка импорта, плюс автоматически при первом открытии, если найден).
После этого «Таймер вебинара» и старый AutoPrintCode Виктора удаляются (просьба пользователя).

## Как устроено (моё решение)

- `autoprint/efir/`: `model.py` (шаблоны, расчёт повестки, JSON, промпт), `store.py` (`data/efir/webinars.json`),
  `legacy.py` (импорт из таймера Виктора), `server.py` (HTTP на 127.0.0.1:8791 — страница, SSE с состоянием,
  файлы с Range, выбор фона из галереи), `page/` (страница эфира и галерея, один HTML без сборки).
- `autoprint/ui/efir_*.py`: окно «Эфир», редактор шаблона, окно таймера, контроллер (состояние экрана).
- Порт постоянный: открытая вкладка переживает перезапуск программы (EventSource переподключается сам).
- Версия 0.7.0; обновления — из репозитория пользователя (DanT2000), не Виктора.
