# 0.11 — урок по событиям, экран учеников со слайдами, правка как в Word

Дата: 2026-11-24. Основа — отзыв владельца после первого запуска 0.10 и ревью преподавателя-методиста
(агент), которому владелец поручил решить про презентации.

## Зачем

Учитель ведёт урок по событиям: дочитал разминку — пошёл дальше. 0.10 ведёт по часам:
- сворачивает недочитанный этап;
- сам прокручивает ленту;
- открывает второй план — окно таймера «Эфира».

Учителю, который не программирует, мешают ещё три вещи:
- разметка `**…**` в заметках;
- «Печать ⚙» в уроке без кода;
- нет способа провести урок по своей презентации.

Цель 0.11: экран урока — единственный пульт урока. На нём текст для учителя, план, кнопки экрана
учеников и слайды. Остальное по желанию.

**Не цели (потом):**
- живой просмотр экрана учеников;
- «на проектор» одной кнопкой;
- технологическая карта;
- «✂ можно сократить» с подсказкой при отставании;
- анимации и видео внутри слайдов;
- курсы и папки;
- заметка после урока;
- шаблоны структуры, сохранённые пользователем.

## Решения

### 1. «Урок» не делает ничего сам

- Этапы в «Уроке» раскрыты все. Пройденные приглушены, но не свёрнуты.
- Смена этапа по часам:
  - ничего не сворачивает и ленту не прокручивает;
  - если текущего этапа не видно, внизу плашка «↓ Идёт: Разбор 1», по щелчку — к нему;
  - то, что раскрыл или свернул учитель, не сбрасывается.
- В шапке плана: «Свернуть пройденные · Свернуть всё · Развернуть всё».
- Настройка «Пройденные этапы» — приглушать (по умолчанию) или сворачивать.
- С карточек убрано «Следующий · через». «Осталось» на текущем этапе — по настройке «Таймер на этапе»,
  по умолчанию включён.

### 2. Один план

- Вид плана — настройка; в «Подготовке» план всегда сбоку.
  - **Сбоку** — как сейчас.
  - **Строкой** — по умолчанию в «Уроке»: `‹ прошлый · ● текущий 3:12 из 8 · следующий (8) › · конец 19:30 · У учеников: Слайд 7`.
    Щелчок по названию — к этапу. «▾» раскрывает полный план поверх ленты.
  - **Скрыть**.
- «Конец 19:30» — плановое время конца по времени начала. Если этапы сдвигали «Начать этот этап
  сейчас», рядом пишется «+4 мин».
- «Начать урок» больше не открывает окно таймера «Эфира». Настройка «При начале урока открывать»:
  - мини-таймер — по умолчанию нет;
  - экран учеников (вкладку) — по умолчанию нет.

  Таймер «Эфира» остаётся для вебинаров без урока и как окно поверх всех.

### 3. Экран учеников — с экрана урока

- В шапке в режиме «Урок» — «У учеников: Фон / Слайд 7 / Перерыв 06:12 / Зарядка».
- Рядом кнопки:
  - **Фон**;
  - **Перерыв ▾** — щелчок сразу начинает перерыв на минуты текущего этапа-перерыва или на перерыв
    оформления; «▾» — 5 / 10 / 15 / 20 мин;
  - **Зарядка** — если в оформлении есть видео;
  - **Открыть экран учеников** — если вкладка не открыта.
- В окне таймера «Перерыв» тоже без поля, забирающего фокус: кнопки 5 / 10 / 15 / 20 и плановые минуты,
  выделенные первыми.
- «⋯ → Оформление экрана учеников»: список, «Изменить…» и «Новое…». Они открывают редактор оформления
  «Эфира» поверх всех окон.

### 4. Мои настройки и масштаб

- Кнопка «Аа» в шапке открывает «Мои настройки»:
  - **Размер текста** 100–200 % (шаг 10). Также Ctrl+= / Ctrl+− / Ctrl+0 и Ctrl+колесо, запоминается.
  - **План в «Уроке»** — строкой / сбоку / скрыть.
  - **Пройденные этапы** — приглушать / сворачивать.
  - **Таймер на этапе** — вкл / выкл.
  - **При начале урока открывать** — мини-таймер, экран учеников.
- Хранятся в settings.json: `page_zoom`, `page_plan`, `page_past`, `page_stage_timer`, `start_timer`,
  `start_screen`. Команда страницы — `prefs`.
- Серые подписи этапов («1. Первая половина · теория…») — 14 px и контрастнее.

### 5. Правка как в Word

- Заметка правится на месте без видимой разметки, через `contenteditable`.
- Панель при правке: Ж, К, • список, 1. список, `код`, ссылка, «Очистить оформление». Ctrl+B / Ctrl+I / Ctrl+K.
- Внутри по-прежнему Markdown. Набранное в поле хранится как есть (`x**2`, «2024. Год» — экранированием `\*`, `\.`);
  жирный — кнопкой «Ж» или Ctrl+B. (Решение после проверки: `**` в заметках к урокам Python — степень, а не жирный.)
- Вставка из Word, PDF или браузера сохраняет жирный, курсив, списки, ссылки и абзацы. Остальное
  срезается до текста.
- У «Спроси» отдельные поля:
  - «Вопрос» (с оформлением);
  - «Ответы учеников» — строки, «+ ответ».

  В Markdown это по-прежнему строки «→ …».
- У «Термина» поля «Термин» и «Определение»; в Markdown первая строка — термин.
- Палитра «+» по группам:
  - **Речь:** Говоришь, Своими словами, Термин, Спроси;
  - **Ученикам:** Задание, Если застрял, Для быстрых, Домашнее задание;
  - **Действия:** Делаешь, Показываешь;
  - **Для себя:** Важно, Типичные ошибки, Заметка;
  - **Материалы:** Слайд или картинка, Код, Результат кода;
  - **Этап**.

  «Код» последним в «Материалах».

### 6. Роли

- Названия «Говоришь», «Расскажи» и «Спроси» оставлены: ими пользуется владелец. На плашке рядом с
  названием — как читать:
  - «Говоришь · дословно»;
  - «Расскажи · своими словами»;
  - «Термин · дословно»;
  - «Спроси · ответы учеников».
- Переименования:
  - «Ловушки» → «Типичные ошибки»;
  - «Вывод» → «Результат кода»;
  - `hint` «Подсказка» → «Если застрял» (теперь в палитре).
- Новые роли:
  - `homework` «Домашнее задание». Попадает в тетрадку учеников; в меню блока — «Скопировать для чата».
  - `goal` «Цель урока». Ставится в начало, печатается первой.
- Урок без кода: «Печать ⚙» в шапке не показывается.

### 7. Презентации — урок по слайдам

- Новое поле блока-картинки `slide` — номер слайда, 0 — обычная картинка. На ленте:
  - подпись «Слайд N»;
  - кнопка «На экран»;
  - отметка «у учеников», если он сейчас показан.
- **Импорт** — «Новый урок → Из презентации…», а также перетаскивание .pdf или .pptx в «Импорт».
  - **PDF:** каждая страница — блок-слайд шириной 1600 px, подпись — первая строка текста страницы.
    Один этап «Презентация» на 45 мин.
  - **PPTX:** порядок слайдов берётся из `ppt/presentation.xml`.
    - Картинки:
      - PowerPoint установлен — тихо сохранить в PDF через COM (PowerShell, без окна; PowerPoint
        закрывать, только если мы его запустили);
      - иначе — сообщение «Сохраните презентацию как PDF и выберите оба файла».
    - Разделы PowerPoint становятся этапами.
    - Заметки докладчика ложатся под свой слайд. Пометки «Скажи:» / «Спроси:» (и «→») / «Сделай:» /
      «Термин:» / «Важно:» / «Задание:» дают роли, без пометок — «Расскажи».
    - Если страниц PDF меньше, чем слайдов (скрытые слайды), заметки идут по номерам до конца PDF,
      о расхождении сказано в сообщении.
- **Экран учеников показывает слайд.** Новый режим экрана `slide`; картинка вписана в экран, следующий
  слайд грузится заранее.
  - В «Уроке» листать: ◀ ▶, PageUp / PageDown (их шлёт пульт-кликер), «На экран» на слайде.
  - B или «.» — фон.
  - Слайд у учеников меняется только по действию учителя.
  - Перелистывание отмечает «я здесь» и прокручивает ленту — это действие учителя.
- **Нейросеть в своём чате.**
  - «Скопировать промпт» работает без материала: «материал приложен к сообщению».
  - Ответ просим в нашем формате .md одним блоком ```markdown, роли и пример на два слайда в промпте.
  - Для урока со слайдами — «⋯ → Промпт для слайдов (в свой чат)»: число слайдов, их текст, правило
    `![Слайд N](slide:N)` для каждого слайда.
  - Ответ — «⋯ → Вставить ответ нейросети».
    - Получается копия урока: этапы и заметки по ответу, слайды подставлены по номерам.
    - Перед добавлением — проверки: сумма минут, несуществующие слайды, слайды без заметок.

### 8. Печать

- «⋯ → Распечатать или PDF…» открывает маленькое окно:
  - **размер текста** — мелко / обычно / крупно;
  - **ответы к вопросам** — да / нет;
  - **код** — да / нет;
  - **слайды** — крупно / миниатюрами / без.
- Цвет плашек печатается (`print-color-adjust: exact`).

### 9. Новый урок по шаблону структуры

«Новый урок» ▾ (в окне программы и в списке уроков на странице):
- **Пустой** — как сейчас;
- **Школа, 45 мин** — оргмомент 2, актуализация 5, новый материал 15, закрепление 15, рефлексия 5,
  домашнее задание 3;
- **Онлайн-занятие, 90 мин** — приветствие 5, разминка 5, теория 15, практика 20, перерыв 10,
  практика 20, итоги 10, домашнее задание 5;
- **Пара, 2×45** — первая половина 45, перерыв 10, вторая половина 45;
- **Из презентации…**

### 10. Переименования

- «Этап заново с этой минуты» → «Начать этот этап сейчас».
- «Распознать сценарий» → «Разложить по этапам».

### 11. Образцовый урок

- Цель — ролью «Цель урока».
- После теории — «Спроси» с проверкой понимания.
- В «Итогах» — рефлексия: «Оцените себя от 1 до 5 в чат».
- «Домашнее задание» — новой ролью.
- Заметка «Как читать этот урок» убрана.

## Ограничения

- Тесты невидимы: offscreen Qt и Edge без окна.
- PowerPoint в тестах не запускается — подмена вызова.
- settings.json старых версий читается. Новые поля — со значениями по умолчанию.
- `Block.slide` — новое поле, по умолчанию 0. Формат .md: картинка с `slide:N` или подписью «Слайд N».

## Что проверить отдельно

1. Смена этапа по часам не меняет раскрытое и не двигает ленту, пока учитель читает.
2. Правка с панелью → Markdown → снова в редактор — то же оформление. Вставка из Word не тащит стили.
3. Кликер ◀ ▶ во время правки заметки не листает слайды.
4. PPTX со скрытым слайдом: заметки не сдвигаются молча.
5. Экран учеников со слайдом переживает перезапуск программы так же, как перерыв.
