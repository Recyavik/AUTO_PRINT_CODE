# Суфлёр урока — дизайн

Дата: 2026-11-23. Макет (согласован, с правками пользователя): https://claude.ai/artifact/YUcs6veTXmQsRpmEEYi65u

## Зачем

Преподаватель ведёт много разных курсов (КБ 8–9 для ФУ в LMS 1Т, «Создание сайтов» и Django в Kodland,
Kotlin). Материалы у всех разные: методичка Kodland (розовым — речь, «Важно!», «#задание», код), расшифровка
видеоурока, выгрузка из LMS, презентация. Нужен один общий формат урока, в который нейросеть раскладывает
любой такой материал, и страница-суфлёр, по которой урок ведётся «по шагам»: этап, с какой по какую минуту,
что сказать, что показать, что спросить, — чтобы не сбиваться и меньше ошибаться.

Ближе всего к цели — пилотный PDF-суфлёр «Занятие 4» (блоки «говоришь / расскажи / спроси / делаешь /
ловушки / для быстрых»), но в программе, живой (по времени) и без привязки к устройству конкретной LMS.

## Цели

- Один формат урока = нынешнее занятие AutoPrintCode (ячейки, как в Jupyter) + ячейки «Этап» и «Картинка»
  + новые виды текстовых ячеек. Старые занятия работают как раньше (это уроки без этапов).
- Страница суфлёра в браузере (на соседнем мониторе; ученики видят только захваченную вкладку, поэтому
  суфлёр им не виден): план с минутами, этапы, блоки со значками, текущий этап по часам, остаток времени.
- Значки вместо подписей; расшифровка — по кнопке «Обозначения». «Важно» — цветом текста.
- Код: подсветка, значок языка в правом верхнем углу, отметка «печатается следующим · Ctrl+F9»;
  щелчок по коду на странице делает его следующим для печати.
- Ссылки кликабельны (Markdown и голые адреса). Картинки — миниатюрами, по щелчку крупно.
- Время — от «Эфира»: «Начать урок» запускает эфир из этапов урока (таймер, перерыв, зарядка, плашка сверху).
- Нейросеть: «Сценарий урока» — из методички/презентации (PDF, DOCX, PPTX, текст) в этот формат;
  «Скопировать промпт» для своего чата тоже работает. Слайды PDF можно прикреплять к этапам картинками.

## Не цели (сейчас)

Печать картинки в Jupyter (буфер + Ctrl+V), показ слайда ученикам на экране «Эфира», картинки слайдов из
PPTX, переименование программы, слияние исправлений Виктора 0.6.x.

## Подходы

1. **Страница в браузере через локальный сервер «Эфира» (выбран).** Тот же сервер 127.0.0.1:8791, новый
   канал состояния. Вид — ровно как макет (HTML/CSS), печать в PDF — средствами браузера, обновление — SSE.
   Открывается отдельным окном Edge `--app` (без вкладок — не перепутать с захватываемой вкладкой).
2. Окно Qt (виджеты/QTextBrowser): своё окно программы, но богатую вёрстку макета Qt не потянет без
   QtWebEngine (+150 МБ к установщику).
3. Только PDF-документ (как пилот): нет «живого» времени и печати кода.

## Формат

`Block.type`: `markdown` | `code` | `stage` | `image`.

- **Этап** (`stage`): `title` — название, `minutes`, `stage_kind` (`""` | `break` | `exercise`), `part` —
  раздел (группа в плане, например «Тёмная тема»), `text` — короткая пометка («теория · на платформе»).
  Блоки после этапа принадлежат ему до следующего этапа; блоки до первого этапа — «перед уроком».
- **Текстовые роли**: прежние `text`, `task`, `explain`, `hint` + `say` (Говоришь — почти дословно), `tell`
  (Расскажи — своими словами), `ask` (Спроси; строки «→ …» — ожидаемый ответ), `do` (Делаешь — вслух не
  читать), `important` (Важно), `show` (Показываешь — что видят ученики), `trap` (Ловушки), `extra` (Для
  быстрых).
- **Картинка** (`image`): `text` — путь к копии файла в `data/media/` или адрес http(s); `title` — подпись.
- `Template`: `start` («ЧЧ:ММ», плановое начало), `preset` (id шаблона «Эфира» — фон, зарядки, перерыв).

JSON нейросети: `{"format": "autoprintcode-lesson", "version": 2, "title", "blocks": [...]}`;
`{"type": "stage", "title", "min", "kind", "part", "note"}`, `{"type": "say", "text"}`,
`{"type": "ask", "text", "answer"}`, `{"type": "image", "slide": N | "url", "caption"}`,
`{"type": "code", "lang", "code"}`. Код в сценарии не обязателен.

## Страница

`/lesson` на сервере «Эфира»; канал `lesson` в SSE (`/events?ch=lesson`), команды — `POST /lesson/cmd`
(JSON, заголовок `X-Suflor`, проверка Host/Origin). Показывается урок, идущий в «Эфире», иначе открытый в
программе. Состояние строит Python: Markdown → HTML (своё, с экранированием), код → HTML (Pygments, как в
редакторе), значки языков — SVG devicon (MIT) из `efir/page/lang/`. Время считает страница от якоря эфира.

Во время урока: пройденные этапы свёрнуты, текущий подсвечен (осталось, полоска), следующий раскрыт,
остальные свёрнуты (раскрываются щелчком). До начала — всё раскрыто. Этап «Перерыв»/«Зарядка» — кнопка
включить его на экране «Эфира». Тема — как в программе; печать — светлая, всё раскрыто.

## Время

`EfirController.launch_lesson(t)`: скрытый шаблон эфира (`Webinar.lesson_id = t.id`, в списке «Эфира» не
виден) — расписание из этапов, оформление из `t.preset` (или последнего выбранного, или первого шаблона, или
по умолчанию). Дальше всё как у эфира: таймер, «Сдвинуть на сейчас», «начать с этапа», перерыв, зарядка.

## Редактор (Qt)

Тип блока — значки ролей + «Этап» + «Картинка». `StageBlockWidget`: название, минуты, вид, раздел, пометка,
время «0:10–0:20». `ImageBlockWidget`: миниатюра, подпись, «Файл…», «Из буфера». Кнопки внизу: Текст · Код ·
Этап · Картинка. В шапке занятия — «Суфлёр урока». Экспорт тетрадки для учеников (без подсказок учителя).
