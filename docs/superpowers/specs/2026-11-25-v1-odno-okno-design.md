# AutoPrintCode 1.0 — одна программа в одном окне

Дата: 2026-11-25. Основа:
- голосовое сообщение владельца после 0.12 («мы делаем совершенно новый софт… сделать красиво»);
- его выбор «Своё окно» — встроенный браузер, а не окно Edge;
- его отзыв на макеты: https://claude.ai/artifact/H8qiTb1b3AMXS687zTsN2T.

## Зачем

Сейчас программа — это три окна, которые живут отдельно:
- окно Qt со списком уроков;
- суфлёр урока в окне Edge;
- плавающий мини-таймер «Эфира».

Плюс вкладка экрана учеников в браузере. Владелец: «у нас две вкладки лежит, автопринт висит, и этот висит… урок мы
можем начать, а кнопку эфир мы не можем нажать».

Меню слишком много: «Новый урок ▾» на шесть пунктов, «⋯» со «Свернуть пройденные / Свернуть все / Развернуть все»,
«меню на меню». Видно много лишних настроек, что-то съехало. Полоса прокрутки плана белая и узкая.
«Ты постоянно делаешь какие-то обрезанные версии, и это меня раздражает… Наша главная задача сделать красиво».

Нужна **одна полноценная программа**. В одном окне:
- список уроков;
- создание урока по шагам;
- подготовка;
- сам урок;
- эфир;
- настройки.

Эфир — часть урока: план урока и есть эфир. Эфир без урока (по шаблону вебинара) тоже есть, в том же окне.

## Что сказал владелец (дословно по смыслу)

- **Окно.** Одно окно, как полноценная программа. «Своё окно» со встроенным браузером, а не Edge.
- **Новый урок — одно действие, дальше по шагам.**
  - Выбрать готовый план (онлайн-занятие, пара, школьный урок) или пустой урок.
  - Импорт файла — внутри.
  - Свой план можно создать прямо здесь: «создал себе график, и он всегда будет такой».
  - Источник текста урока:
    - файл методички прямо нейросети;
    - вставить текст — не называть это «через свой ChatGPT»;
    - сгенерировать через подключённый Claude Code или Codex («подумать надо, сделать хорошо»).
- **Экран учеников и перерыв — наверху, рядом с «Урок не начат».** Места не занимать.
  - Вместо надписей «Фон / Зарядка / Перерыв / Слайд» — маленькие картинки-значки, как в светлом варианте макета.
  - При наведении значки подписаны.
- **Ничего не включается само.** Зарядку и перерыв учитель включает кнопкой: «минута туда, минута сюда — погоды не
  поменяет».
- **Оформление.**
  - Светлая и тёмная тема — в настройках.
  - Масштаб «больше-меньше» — «многие читают не очень хорошо».
- **Вид урока — ближе к варианту А** (план слева, текст карточками). «Оба красивые… я бы сделал оба варианта
  доступными»: план сбоку, план лентой сверху или скрыт. Переключать можно.
- **Мелочи.** Значок набора кода — клавиатура. Ровное выравнивание. Широкие тёмные полосы прокрутки.
  «Пройтись по деталям. Довести всё до ума».
- **Списки уроков, маленький режим, эфир без урока** — «понятно», «теория нормальная».
- «Приступай».

## Цели

1. **Одно окно AutoPrintCode** со своим значком и своей шапкой. В нём всё, что сейчас разбросано по главному окну,
   суфлёру в Edge, мини-таймеру, окнам «Эфира», настройкам и диалогам. Отдельным остаётся только экран учеников —
   вкладка в браузере учителя.
2. **Новый вид**: свои шрифты, цвета, значки, ровная сетка; светлая и тёмная тема; масштаб 80–200 %.
3. **Меньше видимых меню.** Редкие действия собраны в одно плоское меню урока без подменю. Остальное — на своих местах:
   кнопки у самих вещей, правый щелчок, настройки.
4. **Пошаговое создание урока и плана.**
5. **Эфир внутри урока**: полоса наверху показывает время этапа и что видят ученики. Значки «Фон / Зарядка / Перерыв /
   Слайд» всегда под рукой.
6. **Маленький режим** — то же окно, уменьшенное и поверх всех окон, вместо мини-таймера.
7. **Ничего не потерять.** Каждая возможность из старых окон есть в новом. Проверочный список — раздел «Было → стало».

**Не цели:**
- переписывать движок (набор кода, хоткеи, эфир, нейросеть, импорт и экспорт, обновления, хранение уроков);
- менять экран учеников — его видят ученики, менять его не просили;
- веб-версия Виктора (`web/`) — не трогаем;
- проектор, режим докладчика, звонок — 0.12-бэклог, потом.

**Анти-цели (что будет провалом, даже если работает):**
- снова три окна: Edge-суфлёр, отдельный таймер, отдельные окна настроек и эфира;
- «урезанная версия»: возможность из списка «Было → стало» пропала без замены;
- меню в меню, вложенные подменю, «⋯» с десятком пунктов;
- что-то включается ученикам само;
- во время прямого эфира на экране учителя появляется что-то лишнее, а у учеников — что-то кроме их вкладки;
- тесты открывают окна, трей или уведомления на экране владельца.

## Ограничения

- **Платформа.** Windows 11, Python 3.14, PySide6 6.11. В .venv уже есть QtWebEngine (Qt6WebEngineCore), а у
  PyInstaller 6.22 есть хуки для PySide6.QtWebEngine*. Установщик вырастет примерно с 29 до ~110 МБ — владелец
  согласился.
- **Учитель захватывает в демонстрации вкладку браузера.** Поэтому экран учеников остаётся страницей `screen.html` во
  вкладке его браузера. Программа открывает её сама, как сейчас.
- **Данные пользователя переносятся без потерь:**
  - уроки и планы — `templates.json`;
  - эфир — `efir/*.json`;
  - настройки — `settings.json`;
  - картинки и звуки — `media/`, `sounds/`.
- **Тесты невидимы.**
  - Qt — offscreen; страница — в Edge без окна со своим профилем (`tests/cdp.py`).
  - Чужие процессы не трогаем.
  - Настоящих нажатий и щелчков нет.
- **Устанавливать** — только убедившись, что эфир не идёт (`live` пуст в `efir/schedules.json` и `webinars.json`), и
  с резервной копией данных.
- **Коммиты** — в ветку `redesign-pastetalk-ui`. Пуш — в fork. Подпись — «Co-Authored-By: Claude Opus 5.5
  <noreply@anthropic.com>». Личные неотслеживаемые файлы (`примеры_1.2.ipynb`, `info.txt`) не коммитим.

## Подходы к «одному окну» (выбор владельца)

1. **Своё окно Qt со встроенным браузером (QtWebEngine)** — выбрано.
   - Настоящее окно программы: свой значок, своя шапка, поверх всех окон, маленький режим.
   - Нативные окна выбора файлов; перетаскивание файлов с настоящими путями. От Edge не зависит.
   - Цена — размер установщика.
2. **Окно Edge (`--app`) как вся программа.** Установщик не растёт. Но значок на панели задач — Edge, поверх всех
   окон не закрепить, открывается 1–2 с, зависит от профиля Edge, окна выбора файлов выскакивают отдельно. Отклонено.
3. **Всё на виджетах Qt.** Текст урока с кодом, подсветкой и правкой на месте уже есть как веб-страница; переписывать
   его на виджеты — дольше и некрасивее. Отклонено.

## Устройство

### Оболочка (Qt) и движок

- **`AppWindow`** — новое главное окно, наследник `FramelessWindow` (`ui/frameless.py`).
  - Свой заголовок Qt не рисует; всю клиентскую область занимает один `QWebEngineView`.
  - Нативная рамка остаётся: прилипание к краям, Win+стрелки, разворот двойным щелчком, системное меню, тень, скруглённые углы.
- **Перетаскивание окна.**
  - Страница помечает области-«ручки» атрибутом `data-drag`: пустое место шапки, в маленьком режиме — табло.
  - Прямоугольники «ручек» и «дырок» (кнопки и поля внутри ручек) в CSS-пикселях, с учётом масштаба страницы,
    страница сообщает командой `window/regions` — при изменении раскладки и размера.
  - `WM_NCHITTEST` окна возвращает `HTCAPTION` внутри ручки и вне дырок, края — для изменения размера, остальное — `HTCLIENT`.
  - Запасной путь, если child-окно WebEngine перехватывает хит-тест: на «потянул ≥ 4 px с зажатой кнопкой» страница
    шлёт `window/move`, окно делает `startSystemMove()`. Только при зажатой левой кнопке.
- **Кнопки окна** — «Свернуть», «Развернуть», «Закрыть», «Поверх всех окон», «Маленький режим» — рисует страница.
  Они шлют команды `window/*`.
- **Движок остаётся как есть.** Без Qt-окон работают: `PrintController`, `HotkeyManager`, `InputGuard`, `UpdateManager`,
  трей, `EfirController` (без `show_window` / `show_timer` / `edit*`), `LessonController` (без `PageWindow`).
  Логика `MainWindow` (сохранение, планы, импорт и экспорт, обновления, сессия) переезжает в объект `App` без виджетов.
  Его вызывают команды страницы. Хоткеи, трей, guard, «один экземпляр», автозапуск — как сейчас.
- **Профиль WebEngine** — свой, в `DATA_DIR/web`.
  - Встроенные меню и масштаб браузера выключены.
  - Ctrl+колесо и Ctrl+= / − / 0 — масштаб программы.
  - DevTools — только с `--debug`.
- **Запуск без вспышки.** Окно показывается после `loadFinished`. Фон view до загрузки — цвет темы. Пока WebEngine
  стартует, показан знак программы.
- **Набор кода.** В своё окно набирать нельзя (E13): процесс тот же, guard уже это отсекает.

### Сервер, состояние, команды

- **Страница программы** — `GET /app` (новый `page/app.html` + ES-модули `page/app/*.js`, стили `page/app/app.css`,
  шрифты `page/fonts/*.woff2`). Её загружает `AppWindow`.
  - `/lesson` больше не нужен как окно. Адрес оставить и перенаправить на `/app#/lesson`: вдруг открыт в браузере после
    обновления.
  - Экран учеников `/`, `/media`, `/events`, `/report`, `/pick` — без изменений.
- **Каналы SSE:**
  - `lesson` — открытый урок, как сейчас: `scenario.lesson_state`;
  - новый `app` — всё остальное, что показывает окно: список уроков и планов, расписания и оформления эфира, состояние
    набора кода, состояние экрана учеников, обновление, нейросеть (подключена ли, кто), уведомления, нужные окну
    настройки (без ключей), режим окна (большое / маленькое, поверх).
- **Команды — `POST /app/cmd`.** Тот же разбор, что `/lesson/cmd`: заголовок `X-Suflor`, `Origin` — своя страница.
  - Команды урока остаются в `LessonController.command`.
  - Новые команды — в `App`: библиотека, мастер, эфир, настройки, окно, листы.
  - Нужен ответ (окно выбора файла, «получилось / нет») — `POST /app/call`. Он ждёт результата в потоке интерфейса до
    10 мин (окно выбора файла открыто, пока человек выбирает). Ответ: `{ok, result | error}`.
- **Правка урока** — `/lesson/edit` и `/lesson/upload`, без изменений.
- **Файлы.**
  - Выбор — нативные `QFileDialog` (поверх окна), через `/app/call`.
  - Перетаскивание файлов в окно ловит Qt и отдаёт странице событием `{type:"drop", files:[{path,name,size,ext}]}` в
    канале `app`. Страница решает по месту:
    - на «Уроках» и в «Новом уроке» — импорт или материал;
    - в уроке — картинка;
    - в оформлении — фон или видео.
- **Подтверждения и вопросы** («Удалить урок?», «Завершить урок?») — листы внутри окна, не `confirm()`.
  `QMessageBox` остаётся только для сбоя до загрузки страницы.

### Вид

Токены — из макета «Пульт».

**Тёмная тема:**
- фон `#161A22`, панель `#1C212B`, приподнятое `#242A36` / `#2D3442`, утопленное `#11141A`;
- текст `#E9EDF3`, второстепенный `#A6AFBE`, бледный `#858FA0`;
- акцент янтарь `#F2B54D`, «идёт» `#FF6B5E`, «хорошо» `#6AD3A0`.

**Светлая тема:**
- фон `#EEF0F3`, панель `#FFFFFF`;
- текст `#181C24`, второстепенный `#525B6B`, бледный `#636C7D`;
- акцент чернильно-синий `#2B58CF`, «идёт» `#D2382E`.

**Цвета ролей и подсветки кода** — как в `ui.css` макета. Контраст текста ≥ 4.5:1 на своём фоне.

Остальное:
- **Тема.** «Как в Windows / Тёмная / Светлая» (`theme`). Решает Python (`theme.dark`); страница получает `dark` в
  канале `app` и ставит класс.
- **Масштаб.** Один на всю программу: `page_zoom` 80–200 %, шаг 10. Ctrl+колесо, Ctrl+= / − / 0, кнопка «Аа» в шапке,
  «Вид» в настройках. Без перезапуска. `ui_scale` больше не показывается — переносится миграцией.
- **Шрифты.** Onest (текст) и JetBrains Mono (код, время) лежат в программе файлами woff2 с лицензиями OFL — работают
  без интернета. Кириллица и латиница.
- **Значки** — свой набор SVG в духе макета: линия 1.8, скругления. Набор кода — клавиатура. Роли — свои значки.
- **Полосы прокрутки** — 14 px, ползунок в цвет темы, на ховере ярче.
- **Фокус клавиатуры** виден везде. Колесо мыши меняет поле, только если поле выбрано (как `WheelGuard` сейчас).
- **Подсказки** — своя всплывающая подсказка: быстро, в стиле программы. У значков без подписи — обязательно.
- **Движение.** Только в ответ на действие: открытие листа, раскрытие этапа. Сам ничего не мигает, кроме метки
  «Идёт» и одного мягкого пульса значка, когда начался этап «Перерыв» или «Зарядка».

### Экраны

#### Шапка окна (на всех экранах)

Одна строка 44 px:
- знак программы;
- «хлебные крошки» («Уроки / Django: формы»);
- в уроке — стрелка «▾» у названия: меню урока;
- справа:
  - «Аа» — масштаб: «−», «100 %», «+», «Обычный»;
  - «Поверх всех окон»;
  - «Маленький режим»;
  - «Свернуть», «Развернуть», «Закрыть».

Пустое место шапки тянет окно. Кнопка «Закрыть» сворачивает в трей:
- если в настройках включено «Сворачивать в трей при закрытии»;
- всегда, пока идёт эфир.

В первый раз появляется подсказка «Программа работает в трее».

#### Боковое меню разделов (кроме урока и маленького режима)

- **«Уроки»** — со счётчиком.
- **«Эфир»** — с меткой, если эфир идёт.
- внизу — **«Настройки»**.
- Есть обновление — внизу же кнопка «Обновить до X».

#### «Уроки»

- **Заголовок.** Поиск «Найти урок» и одна главная кнопка «Новый урок» (Ctrl+N).
- **«Продолжить».** Последний открытый урок: название, план, сколько этапов, кода и слайдов, кнопка «Открыть». Идёт
  урок — вместо этого «Идёт урок · этап 4 из 7 · осталось 18:12» и «Вернуться к уроку».
- **«Планы».** Карточки с полосой этапов (ширина — минуты, цвет — вид этапа) и «N этапов · M уроков».
  - Щелчок — открыть план (правка этапов).
  - Кнопка на карточке — «Новый урок по плану».
  - Последняя карточка — «Новый план».
- **«Все уроки».** Группы по плану, последняя — «Без плана».
  - Строка урока: название, длительность, когда менялся. У идущего урока — метка.
  - Двойной щелчок или Enter — открыть. F2 — переименовать.
  - Правый щелчок — то же меню урока, что в шапке урока.
- **Перетащить файлы в окно** — импорт: .autoprint, .zip, .ipynb, .md, .py, .json, .pdf, .pptx. Если в файле урок по
  сценарию с ⏱ — предложить «Разложить по этапам».
- **Образцы** (`samples_seen`) — как сейчас.

#### «Новый урок» — по шагам

Шаги вверху — номера, потому что это последовательность: «1 План» — «2 Тема и текст».

**Шаг 1. «На чём построить урок?»**
- **Карточки планов.** Полоса этапов, перечень этапов, одна выбрана. По умолчанию — последний выбранный (`lesson_plan`).
- **«Без плана».** Пустой урок, этапы добавите сами.
- **«Свой план».** Открывает подшаг «Новый план» (ниже). Сохранённый план навсегда в списке и сразу выбран.
- **Строка «Уже есть файл урока?»** — «Выбрать файл…» или перетащить. Импортированный урок открывается сразу, без шага 2.
  - Пакет .autoprint — с планами и оформлениями.
  - Презентация .pdf или .pptx — урок по слайдам. Pptx с одноимённым pdf рядом берёт картинки слайдов из него.
  - Во время эфира презентации не импортируются, сообщение как сейчас.
- «Отмена» и «Далее».

**Подшаг «Новый план».**
- «Название».
- «Начать с»: «Пусто», «Онлайн-занятие 90 мин», «Пара 2×45», «Школьный урок 45 мин» (`STRUCTURES`).
- Список этапов: название, минуты, вид («Обычный / Перерыв / Зарядка»), у зарядки — видео из оформления. Выше / ниже,
  удалить, «Добавить этап».
- «Всего 1 ч 30 мин».
- Сохраняет `Template(kind=plan)`. «Назад» — к шагу 1 без сохранения, «Сохранить план».

**Шаг 2. «Тема и текст».**
- «Тема урока» — поле в фокусе.
- «Класс или возраст» — необязательно, `lesson_class`.
- **Выбрано «Без плана»** — ещё «Длительность» (10–600 мин, шаг 5, `lesson_minutes`) и «Перерыв» (0–60, «без
  перерыва», `lesson_break`), как сейчас.
- **«Откуда взять текст этапов?»** — три карточки.
  1. **«Составит нейросеть».**
     - Материал необязателен: перетащить или «Выбрать файл…» (pdf, docx, pptx, txt, md, ipynb, py) либо вставить
       текст или код в поле.
     - Без материала нейросеть составляет урок по теме, плану (или длительности) и классу.
     - Под материалом — «Что это»: «Методичка или презентация — урок по этапам» или «Код — разобрать для набора».
     - Для кода — прежние варианты разбора:
       - «С комментариями / По шагам / По частям»;
       - «Краткое условие задачи», «Пояснения для учеников», «Не менять код — только комментарии и разметка»;
       - «Коротко / Подробно».
     - **«Скопировать задание»** есть и здесь — для своего чата, под выбранное: урок или разбор кода. Ответ
       вставляется в поле «Ответ» этой же карточки. Так не теряется вкладка «Код через нейросеть» с её промптом.
     - Строка «Сделает: <кто> · <модель> · Сменить…». Кто — из настроек нейросети. Сменить — открывает «Настройки →
       Нейросеть» поверх и возвращает назад.
     - Нейросеть не подключена:
       - найдены установленные Claude Code или Codex — кнопки «Использовать Claude Code (по подписке)» / «Использовать
         Codex (по подписке)», они настраивают провайдера одним щелчком;
       - иначе — «Подключить нейросеть…».
     - **Claude Code и Codex читают сам файл.** Копия файла кладётся в пустую рабочую папку агента, агенту разрешено
       только чтение (`--tools Read` у Claude Code, `-s read-only` у Codex). Так он видит картинки слайдов и PDF целиком,
       а не только выдержку текста. У остальных провайдеров — текст из файла, как сейчас (`materials.py`).
  2. **«Вставить текст».** Бывшее «через свой ChatGPT».
     - Три шага на карточке: «Скопировать задание» (план, тема, класс и видео зарядок уже внутри) — «Отправьте в любую
       нейросеть вместе с методичкой» — «Вставьте ответ сюда».
     - Поле вставки понимает всё, что понимает вкладка «Вставить» сейчас: ответ нейросети (`~~~markdown` или JSON),
       Markdown с кодом, тетрадку Jupyter, просто код (тогда язык — «определить сам» или выбрать).
     - «Вставить из буфера».
     - Итог разбора одной строкой, как сейчас: этапы по плану, заметки, код, слайды, фото, «нужно вставить».
     - Пустые места «Слайд N» — «Подставить слайды из презентации…».
  3. **«Заполню сам».** Этапы из плана (или один «Начало»), внутри пусто.
- «Назад» и «Создать урок».
  - Нейросеть работает — ход виден на месте: «жду ответа / думает / пишет — N знаков · м:сс», хвост ответа; «Отмена».
  - Фото по ссылкам качаются в фоне — «Скачиваю картинки: a из b…» и «Пропустить».
- **Итог:** урок открывается в «Подготовке». Разбор кода — режим набора переключается, как сейчас (`result_style`), с
  сообщением.

#### «Урок»: подготовка и урок — один экран

Вариант А из макета, с выбором, где план.

**Эфирная полоса** под шапкой — одна строка, переносится только на узком окне. Слева направо:

1. **Состояние урока.** Метка (серая / красная), крупное время, под ним подпись.

   | Когда | Крупно | Подпись |
   |---|---|---|
   | Не начат | — | «Урок не начат» + «Начало в [18:00 ▾]» («через 12 мин · конец в 19:30»). Пустое время — «Начать в…» |
   | Ждём назначенного начала | обратный отсчёт | «До начала» + «Начать сейчас» |
   | Идёт | «осталось» на этапе | «этап 4 из 7 · Практика: форма регистрации» |
   | Время вышло | «+м:сс» | «Урок окончен» |

   - **Щелчок по состоянию идущего урока** — небольшая панель:
     - «Начало» (поле времени, Enter — сдвиг этапов, Esc — отмена);
     - «Начать этот этап сейчас»;
     - «Следующий этап — сейчас»;
     - «Завершить урок…».

     Сдвиги — с тостом «Время этапов сдвинуто на сейчас» и «Вернуть».
   - **Этапов с минутами нет** — вместо этого «Поставьте этапам минуты» кнопкой, которая ставит курсор в первую.
2. **Часы.** «сейчас 18:36», «конец 19:30», сдвиг «+5 мин», если был.
3. **Экран учеников** — справа.
   - **Миниатюра** того, что у них сейчас: фон, перерыв с отсчётом, зарядка, номер слайда. Под ней — точка состояния
     вкладки.
     - Тексты состояния вкладки: «на связи» / «не открыта» / «щёлкните по вкладке один раз — для звука» / «выключен».
     - Вкладка не открыта — точка серая, миниатюра с кнопкой «Открыть».
   - **Щелчок по миниатюре** — панель:
     - «Открыть вкладку»;
     - «Скопировать адрес вкладки»;
     - «Оформление: <имя> ▾» (выбрать оформление урока);
     - «Изменить оформление…» (раздел «Эфир → Оформления» с этим оформлением).
   - **Четыре значка без подписей**, подсказка при наведении:
     - **«Фон»** — убрать всё, ученикам фон.
     - **«Зарядка».**
       - Одно видео — включить.
       - Несколько — панель с названиями.
       - Идёт — панель «Пауза / Продолжить», «Сначала», «Убрать — снова фон».
       - Значок показывает «м:сс» и, если нужно, «без звука» / «ждёт щелчка» (красная точка + подсказка).
       - Видео нет — значок неактивен, подсказка «Добавьте видео зарядки в оформление».
       - Файл видео пропал — предупреждение заранее, как сейчас.
     - **«Перерыв».**
       - Не идёт — панель «Перерыв — на сколько»: по плану (подсвечено), 5 / 10 / 15 / 20 мин.
       - Перерыв с этапа «Перерыв», который идёт сейчас, кончается вместе с этапом, как сейчас.
       - Идёт — значок показывает «м:сс»; панель «+5 мин», «+1 мин», «−1 мин», «Пауза отсчёта / Продолжить», «Заново»,
         «Убрать — снова фон».
       - Время вышло — «время вышло», через минуту сам фон (как сейчас).
     - **«Слайд».**
       - Показать последний показанный слайд или первый. Слайдов нет — неактивен.
       - Идёт слайд — рядом «‹» «›» и номер. Кликер (← → PageUp PageDown, B) работает, как сейчас.
   - **Нажатый значок** — то, что сейчас у учеников.
   - **Начался этап «Перерыв» или «Зарядка»** — его значок один раз мягко пульсирует и получает точку. Включает учитель.
4. **Главная кнопка.**
   - Не начат — «Начать урок» (основная) с «▾»: «Начать в…» — время, «Начать»; до начала таймер считает «до начала».
   - Идёт — «Завершить» (контурная красная); после конца времени — основная.
   - Идёт другой эфир — спросить листом «Сейчас идёт эфир «X». Завершить его и начать урок?»
5. Под полосой — **тонкая линия всего урока**: отрезки этапов, пройдено — акцентом.

**План урока — три положения.** Переключатель тремя значками в заголовке плана и в «Аа»; хранится в `page_plan`.
- **«Сбоку»** (по умолчанию) — колонка 300 px слева.
  - Строка этапа: время начала, вид (значок зарядки или перерыва), название, минуты.
  - Пройденные — с галочкой и бледные. Текущий — рамка акцента, полоска хода, «идёт · осталось м:сс».
  - Щелчок — прокрутить к этапу.
  - В подготовке:
    - минуты правятся на месте; перетаскиванием меняется порядок;
    - у урока по плану минуты не правятся (замок «из плана»), внизу «Изменить план».
- **«Сверху»** — лента этапов под эфирной полосой. Ширина отрезка — минуты; на отрезке время и название (обрезается,
  целиком — в подсказке). Перерыв — штриховкой, текущий — с заливкой хода. Щелчок — прокрутить к этапу.
- **«Скрыть»** — плана нет, только линия урока под полосой.

**Текст урока** — колонка до 860 px по центру.
- Заголовок этапа: «Этап 4» · название · «18:30–18:55 · 25 мин». Щелчок по заголовку сворачивает или разворачивает
  этап. Пройденные приглушены или свёрнуты — по настройке `page_past`.
- **Роли** — цветные карточки со значком и подписью малыми капителями: «говоришь», «расскажи», «делаешь», «спроси» (и
  «Ответ: …»), «важно», «покажи», «ловушка», «дополнительно»… — все роли, что есть сейчас.
  - «Говоришь» — крупнее: его читают вслух.
  - Обозначения — подсказкой у значка роли, без отдельной «легенды».
- **Код.** Шапка: значок языка, имя файла (если есть), «Скопировать», «Набрать» (клавиатура, основная) и «▾» —
  быстрые настройки набора:
  - «Целиком / По строкам / По шагам»;
  - скорость;
  - «Как человек»;
  - «Звук клавиш»;
  - «Комментарии читать вслух»;
  - «Все настройки набора…».

  Набранные строки подсвечиваются, следующий блок отмечен. «Набрать» — блок становится текущим, отсчёт
  `button_countdown_s` («Поставьте курсор в редактор — 3…»), потом набор.
- **Картинки и слайды.**
  - Миниатюра, номер слайда, подпись, «Показать ученикам».
  - Места «Нужна картинка: …» — «Найти в интернете», «Выбрать файл…», вставка Ctrl+V.
  - Места «Слайд N» — «Подставить слайды из презентации…».
- **«Дальше»** в конце текущего этапа: «Дальше · 18:55 · Перерыв · 5 мин» и «Начать сейчас» («Следующий этап — сейчас»
  с «Вернуть»).
- **Текущий этап вне экрана** — плашка «↓ Идёт: …». Лента сама не прокручивается.
- **Полоса набора кода** снизу (видна, пока идёт набор): значок клавиатуры, «Набираю forms.py · строка 4 из 6 · шаг 2
  из 5», куда («→ VS Code»), полоска хода, «Пауза / Продолжить / Дальше», «Стоп».
  - Слова для чтения вслух (комментарии в режиме «вслух») — над полосой, как сейчас.

**Правка.**
- До начала урока экран в подготовке: всё правится на месте, как сейчас в «Подготовке»:
  - блоки: роль, выше / ниже, удалить, вставка «+ Текст · Код · Картинка · Место для фото» между блоками;
  - Ctrl+V картинок, перетаскивание;
  - Alt+1…9 / Alt+0 — шаги в коде;
  - отмена Ctrl+Z;
  - «✓ Сохранено / Сохраняю… / Нет связи — правки ждут (N)».
- Когда урок идёт — чтение. Переключатель «Правка» (карандаш в полосе) включает правку и во время урока: исправить
  опечатку.
- Отдельных режимов «Подготовка / Урок» больше нет.

**План урока как документ.** Открытый план — тот же экран:
- над текстом полоса «План урока: этапы и минуты для всех уроков по нему (N): <ссылки на уроки>»;
- заметки плана — заготовки для новых уроков;
- вместо «Начать урок» — «Новый урок по плану» и «Начать по плану» (суфлёр только с таймингами), как сейчас.

**Меню урока** — «▾» у названия в шапке; оно же — правый щелчок в «Уроках». Плоское, без подменю:
- «Переименовать»;
- «Дублировать»;
- «Экспорт…» — лист: формат «Урок одним файлом (.autoprint) / Markdown (.md) / .ipynb / Тетрадка для учеников (только
  код) / .json»; для .autoprint — галочки, как в «Урок одним файлом»;
- «Печать или PDF…» — лист, как сейчас: размер, слайды, ответы, код. Внизу две кнопки:
  - «Сохранить PDF…» — `QWebEnginePage.printToPdf` в выбранный файл, потом файл открывается;
  - «Печать…» — системный выбор принтера (`QPrintDialog`), печать `QWebEngineView.print`.

  Встроенный браузер не умеет окно предпросмотра Edge — поэтому PDF отдельной кнопкой;
- «План урока…» — лист: «Открыть план «X»», «Отвязать от плана», «Привязать к плану» (список), «Сделать из этапов план»
  — что применимо;
- «Обновить по ответу нейросети…» — лист: «Скопировать задание» (для слайдов — по слайдам), поле ответа,
  «Добавить урок»; получится копия, исходный урок не меняется;
- «Подставить слайды из презентации…» — если есть пустые места «Слайд N»;
- «Разложить по этапам (⏱ этапы, 🗣 реплики)» — если похоже на сценарий;
- «Удалить…».

#### Маленький режим

То же окно: уменьшается (своя запомненная геометрия, по умолчанию 360×600 у правого края) и встаёт поверх всех окон
(`efir_pinned`). Входит кнопкой в шапке и из трея; выходит кнопкой «Большой режим». Тянуть можно за любое пустое место.

**Раскладки по размеру** — как у старого таймера:

| Размер | Что видно |
|---|---|
| Совсем маленький (высота < 150 или ширина < 260) | только «сейчас»: название и время |
| Узкий и высокий (по умолчанию) | метка и «этап i из n»; крупное время; название этапа; полоска; «18:30–18:55 · сейчас 18:36»; «Дальше · 18:55 · Перерыв · 5 мин»; экран учеников (четыре значка с подписями сеткой 2×2); «Следующий этап»; набор кода (имя, i из n, пауза, стоп) |
| Широкий и низкий (ширина ≥ 640, ширина ≥ 2.6 × высоты) | «сейчас» слева, повестка ячейками направо, «‹ N» / «N ›» |
| Большой (≥ 560 × 230) | «сейчас» слева, список этапов справа |

Время краснеет в последнюю минуту. Нет урока и эфира — «Нет эфира».

#### «Эфир»

Эфир без урока — вебинар по расписанию. Две вкладки: «Расписания» и «Оформления».

**«Расписания».** Слева — список: название, «● идёт», «всего · блоков · перерыв · оформление», цепочка блоков. Справа —
выбранное:
- **Заголовок.** «Запустить» — панель старта:
  - «Сейчас»;
  - ближайшие :00 / :30;
  - прошлое время этого шаблона;
  - поле «Начать в это время».

  Идёт — «Открыть эфир». Рядом «Изменить».
- **Повестка.** Время от начала, вид, название, минуты; у блока — «экран вкл / выкл» точкой.
- **Оформление** — три миниатюры («Фон», «Заставка перерыва», «Зарядки · N видео») и выбор оформления.

**Меню расписания** (правый щелчок или «▾» у названия):
- «Сделать копию»;
- «Экспорт в JSON…»;
- «Скопировать для нейросети»;
- «Выше / Ниже»;
- «Удалить…» (идёт — эфир завершится).

**«Новый эфир»** — те же шаги, что у урока:
1. «Пусто».
2. «По описанию — нейросеть»: поле описания с примером. Нейросети нет — задание копируется.
3. «Вставить текст» — JSON или ответ нейросети; «Скопировать задание с примером».
4. «Из файла JSON».
5. «Из «Таймера вебинара»» — если старая программа найдена. На пустом списке — предложение перенести.

**Правка расписания** — на месте, в правой части:
- «Название», «Оформление»;
- строки: время, название, минуты, вид (угадывается по названию, пока не выбран руками), экран «вкл / выкл / не
  важно», выше / ниже, добавить ниже, удалить (минимум один блок);
- «Добавить блок»;
- «Перерыв по умолчанию»;
- «Экспорт JSON…», «Для нейросети»;
- «Отмена» / «Сохранить». Уйти с несохранёнными — спросить.

**«Оформления».** Список оформлений: фон, зарядки, перерыв, где используется. Правка:
- «Название»;
- «Фон (он же занавес)»:
  - «Чёрный», анимации (Градиент, Сияние, Огоньки, Пузыри, Куб, Звёзды, Трубы), «Свой цвет…», «Картинка…»;
  - галерея фонов вживую;
- «Надпись на фоне»;
- **«Зарядки»** — название кнопки, файл (размер или «⚠ Файл удалён или перемещён» + «Заменить…»), убрать; «Добавить
  видео…» (несколько);
- **«Экран перерыва»** — фон («Как основной» / свой), «Показывать надпись» + текст, «Обратный отсчёт», «Когда время
  вышло», «Шрифт» (как сейчас + свой файл), «Цвет», «Предпросмотр перерыва» (в браузере, ученикам не видно);
- **копия файлов** — см. «Поведение»;
- удалить нельзя, пока оформление используется. Сохранение идущего эфира применяется сразу.

Это исправляет и ошибку: смена фона, шрифта или цвета теперь отмечает «есть изменения».

**Идущий эфир без урока** — экран как урок, но вместо текста — табло:
- «СЕЙЧАС», блок, крупное время, полоска, «Дальше: …», «ДЕМОНСТРАЦИЯ ВКЛ / ВЫКЛ», часы и «Эфир 11:00–13:00»;
- справа или снизу — повестка;
- эфирная полоса та же: значки экрана учеников, «Завершить эфир», панель состояния («Изменить начало…», «Начать этот
  блок сейчас», «Начать с блока…», «Начать эфир сейчас / заново»);
- маленький режим работает так же.

#### Уведомления

Тост внизу окна. Действие в тосте (например, «Вернуть») — кнопкой. В трей — только когда окно скрыто или свёрнуто и
сообщение важно, как сейчас (`_notify`).

### Поведение

- **Экран учеников ничего не переключает сам.** Включают только значки, кликер и команды учителя. Остаётся как сейчас:
  - доигравшая зарядка возвращает фон;
  - вышедший перерыв через 60 с возвращает фон;
  - перерыв с этапа-перерыва кончается вместе с этапом.
- **Вкладку учеников программа открывает сама** при первом перерыве, зарядке или слайде, не чаще раза в 30 с, как
  сейчас. Плюс по настройке — при начале урока.
- **Перезапуск во время эфира** возвращает его, как сейчас (`efir.restore`). Маленький режим восстанавливается, если
  был включён.
- **Идёт урок, открывают другой** — лист «Идёт урок «X». Завершить его и открыть «Y»?». Хоткей «Следующий урок» во
  время урока не работает, как сейчас.
- **Копирование файлов.** «Копировать картинки и видео в программу» (вкл):
  - фон, заставка, видео зарядок и свой шрифт, выбранные в оформлении, копируются в `data/media` (видео тоже);
  - оформление ссылается на копию; картинки уроков копируются уже сейчас;
  - файла нет — «Файл удалён или перемещён» и «Заменить…» на месте (в оформлении и у значка зарядки). Проверяется
    любой путь — в программе или снаружи;
  - **при обновлении до 1.0 файлы уже существующих оформлений не копируются** (видео бывают по сотне МБ — медленный
    первый запуск). Вместо этого:
    - у оформления с файлами снаружи — строка «Файлы снаружи программы: N МБ» и кнопка «Скопировать в программу»;
    - в «Настройки → Урок» — «Скопировать файлы всех оформлений в программу (N МБ)»;
    - копирование — в фоне, с ходом и «Отменой». Ссылка меняется только после успешной копии; ошибка — сообщение,
      ссылка остаётся прежней.
- **Трей:** «Показать окно», «Маленький режим», «Старт / пауза», «Стоп», «Обновление…» (если есть), «Настройки…»,
  «Выход». Щелчок по значку — показать окно. Значок по состоянию набора — как сейчас.
- **Клавиши окна:**
  - Ctrl+N — «Новый урок»;
  - Ctrl+O — выбрать файл для импорта;
  - Ctrl+, — настройки;
  - F1 — «Как пользоваться»;
  - Ctrl+Q — выход;
  - Ctrl+колесо, Ctrl+= / − / 0 — масштаб.

  Глобальные хоткеи — как сейчас.
- **Хоткей «Следующий урок»** открывает следующий урок в окне (не во время урока).
- **Сохранение сессии.**
  - Геометрия большого и маленького окна.
  - Открытый экран (урок или раздел).
  - Был ли маленький режим.

  При запуске открывается то же место. Запуск с `--tray` — сразу в трей.

## Решения строителя по итогам проверки описания

Каждое решение — с ценой ошибки.

1. **Урок по одной теме, без материала, разрешён** (карточка «Составит нейросеть»). Владелец просил «сгенерировать
   через Claude Code или Codex». Цена ошибки — лишний вариант на карточке.
2. **Промежуточные сборки не ставятся** (см. «Установка»). Цена ошибки — владелец увидит новое окно позже, чем мог бы.
3. **«Сохранить PDF…» и «Печать…»** вместо предпросмотра Edge. Цена ошибки — привычного предпросмотра нет.
4. **Файлы существующих оформлений при обновлении не копируются** — только кнопкой. Цена ошибки — до нажатия кнопки
   эти файлы не защищены от удаления.
5. **Проба:** `QWebEngineView` на offscreen работает в этой среде. Страница загрузилась за 2,4 с с запуском движка,
   `runJavaScript` отвечает. Ошибки GPU в журнале — шум. Значит, есть и проба настоящего WebEngine в тестах.

## Риски и первые шаги

1. **WebEngine в сборке** (размер, хуки, `DROP`). Первая задача — сборка с пустой страницей в `AppWindow`, установщик
   собирается, размер записан.
2. **Хит-тест поверх `QWebEngineView`** — там же: окно тянется за шапку, края растягиваются. Не выходит — запасной путь
   `startSystemMove`.
3. **WebEngine offscreen в тестах** — там же; не выходит — тесты оболочки без WebEngine, страница — в Edge.
4. **Объём.**
   - Порядок: оболочка и мост → вид (токены, шрифты, значки, компоненты) → «Урок» (самое важное для живых уроков) →
     «Уроки» и «Новый урок» → маленький режим → «Эфир» → «Настройки» и листы → перенос тестов → сборка.
   - Каждый шаг заканчивается рабочей программой: старые окна убираются по мере замены.
