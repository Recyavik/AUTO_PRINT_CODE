# AutoPrintCode 1.2 — окно на Electron

Дата: 2026-11-26. Основа — голос владельца на 1.1.4: окно «всё ещё дёргается… мои приложения так не дёргаются»;
«Давай переделываем полностью… на электрон внешку».

## Зачем

В 1.0–1.1 окно — Qt (своя рамка, WM_NCCALCSIZE/WM_NCHITTEST) со встроенным браузером QtWebEngine. QtWebEngine рисует
страницу «за кадром»: Windows меняет размер окна сразу, кадр страницы нового размера приходит позже — край окна
дёргается, мелькает пустая полоса. Заплатки 1.1.2–1.1.3 (страница «стоит», пока тянут, и перестраивается после)
дали «стоит, потом прыгает». Chrome, Edge, VS Code (Electron) рисуют страницу в своём окне — край тянется ровно.

## Что меняется (и что нет)

- Страница окна (/app — все экраны) **та же**: она говорит с программой только по HTTP (`/app/cmd`, `/app/call`,
  `/events`), Qt ей не нужен.
- Программа на Python (набор кода, эфир, хоткеи, трей, нейросеть, PowerPoint, файлы) **та же**, Qt (без WebEngine)
  остаётся: трей, таймеры, QPdfDocument, окошки до загрузки окна.
- Меняется рамка: окно — отдельный процесс Electron (`window/`), его запускает программа.

## Устройство

- `window/main.js` (Electron, main): окно без рамки (`frame:false`, края и прилипание — Windows), перетаскивание —
  CSS `app-region` по `[data-drag]` страницы (кнопки и поля — `no-drag`); ссылки наружу, файлы, брошенные в окно,
  печать в PDF и на принтер, системные окна выбора файлов, маленький режим и места окна на экране.
- `window/geometry.js` — расчёт мест (по умолчанию, маленький режим, «вид» маленького режима, в пределах экрана):
  чистые функции, тесты `node --test`. Места считает Electron — у него те же координаты, что у окна (на нескольких
  мониторах с разным масштабом Qt и Chromium считают по-разному).
- `window/preload.js` — файлы, брошенные в окно: настоящие пути (`webUtils.getPathForFile`) уходят программе, как раньше
  из Qt (видео в сотни МБ не копируются через страницу); страница их не видит. Кнопки страницы сбоя.
- `window/fail.html` — «Не удалось запустить окно программы: …» с «Повторить» и «Журнал работы».
- Связь: программа слушает именованный канал (QLocalServer), Electron подключается; строки JSON:
  программа → окно `{op, …, id?}`, окно → программа `{ev, …}` и ответы `{ev:"reply", id, ok, value|error}`.
  Канал закрылся (программа упала) — окно закрывается само.
- `autoprint/ui/shell_window.py` — `ShellWindow`: то, что видели остальные части программы у `AppWindow`
  (show/hide/свернуть/развернуть, состояние, заголовок, маленький режим, «поверх всех», печать, окна выбора файлов),
  а внутри — команды окну и зеркало его состояния (видно/свёрнуто/развёрнуто/в фокусе, места на экране).
  Окно Electron упало — запускается снова (до 3 раз за минуту). `launch=False` — без процесса (тесты), `hidden` —
  окно никогда не показывается (тесты, `--selftest`).
- Места окна в settings — JSON `{x,y,w,h,max}` (большое) и `{x,y,w,h}` (маленькое); прежние строки Qt
  (`saveGeometry`) переводятся при первом запуске.
- Ссылки наружу и «Журнал работы» открывает программа (QDesktopServices / os.startfile) — в тестах это заглушки.
- Страница: убраны отправка «областей окна» (regions) и `__sizemove` — они были для Qt-рамки.

## Сборка

- `tools/build_exe.py`: PyInstaller без QtWebEngine/QtQuick/QML/QtPrintSupport; затем `@electron/packager` собирает
  `window/` в `dist/AutoPrintCode/window/AutoPrintCodeWindow.exe` (значок программы, лишние переводы Chromium
  убраны); `--selftest` собранной программы запускает это окно невидимо и ждёт загрузки страницы.
- Установщик убирает прежнюю `{app}\window` перед установкой; закрывает и окно (Restart Manager).
- Electron 45.3.0 (вышел 2026-11-10), @electron/packager 20.3.0.

## Не цели

- Не переписывать страницу и программу на Node.
- Не менять вид окна: шапка, кнопки окна, маленький режим — как в 1.1.

## Решения без владельца (мои)

- Кнопки окна — свои (страница), не системные (Snap Layouts при наведении на «Развернуть» не будет — как в 1.1).
- Проверка орфографии в полях выключена (в 1.1 её не было).
- Окно показывается, когда страница готова (`ready-to-show`, не дольше 2,5 с) — без белой вспышки и без заставки Qt.
