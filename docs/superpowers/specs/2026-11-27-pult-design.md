# Пульт: управление уроком снаружи (Macro Deck, Stream Deck)

## Зачем

Владелец ведёт уроки и хочет управлять экраном учеников с телефона через Macro Deck: кнопки на телефоне,
Macro Deck на этом ПК выполняет действие. Нужны основные элементы управления и живая информация на кнопках:
прошедший, идущий и следующий этап, сколько осталось, что сейчас у учеников.

## Что решили с владельцем

- Кнопки: Фон, Чёрный, Зарядка, Перерыв, Слайд, ◀ и ▶ (слайды). Стрелок по этапам нет.
- Верхний ряд только показывает: слева прошедший этап, в центре идущий и крупно «сколько осталось», справа
  следующий. Слов «предыдущий» / «следующий» нет — они просто стоят до и после.
- Слайды — как в верхнем меню программы: «Слайд» показывает слайд (ещё раз — фон), ◀ ▶ работают, пока слайд
  показан.
- «Подготовка» — обычная кнопка (как «Фон»): открывает в браузере вкладки, прописанные в самой кнопке Macro Deck.
- Телефон — Samsung Galaxy A20s; страница «Урок» в Macro Deck, другие страницы (свет, дом, мониторинг ПК) — потом.

## Подходы

1. **HTTP-пульт в программе + встроенные действия Macro Deck 3 (выбран).** Программа принимает команды на
   127.0.0.1:8791 с секретным ключом и отдаёт состояние (JSON). В Macro Deck 3.0.2 есть «Send HTTP Request»,
   «Get JSON Value», «Launch Application» и переменные «Read from file» — живое время на кнопке берётся из
   файлов, которые программа обновляет раз в секунду. Работает с любым пультом (Stream Deck, Companion,
   AutoHotkey, curl). Ничего не ставить в Macro Deck.
2. Программа как дополнение Macro Deck по его протоколу (WebSocket, сопряжение). Живые переменные и состояния
   «правильно», но нужен режим разработчика Macro Deck, протокол молодой и может меняться. Отложено.
3. Горячие клавиши. Сталкиваются с набором кода, не дают время на кнопках. Отклонено.

## Решения

- Адрес: `http://127.0.0.1:<порт>/api/<команда>?key=<ключ>` (GET или POST), ключ можно и заголовком
  `X-AutoPrint-Key`. Только этот компьютер (сервер и так слушает 127.0.0.1). Ключ — чтобы чужой сайт в браузере
  не нажимал кнопки (DNS-подмену уже отсекает проверка Host).
- Команды: `background`, `black` (переключатель: чёрный ↔ фон), `exercise` (не идёт — включить видео по
  настройке «Какое видео включать», «спросить» = по очереди; идёт — пауза / дальше), `break` (не идёт — перерыв
  по плану: этап-перерыв, который идёт, иначе первый этап-перерыв урока, иначе минуты по умолчанию; идёт —
  ничего), `break_add` (+5 мин или `min=`), `slide` (переключатель: слайд ↔ фон), `slide_next`, `slide_prev`
  (только пока слайд у учеников), `state`. Ответ любой команды — то же состояние.
- Урок — тот, что в фокусе (идущий, иначе открытый). Идёт вебинар не этого урока — команды экрана идут эфиру,
  слайдов нет.
- Состояние: этапы (прошедший, идущий, следующий), сколько осталось, номер этапа, что у учеников, перерыв и его
  отсчёт, зарядка (пауза), слайд N из M, есть ли слайды.
- Файлы для Macro Deck: `%APPDATA%\AutoPrintCode\deck\*.txt`, по файлу на значение, UTF-8 без BOM, без перевода
  строки; пишутся только при изменении; `state.json` — всё вместе.
- Настройки → «Пульт»: включатель (по умолчанию выключен), ссылки с ключом для копирования, «Новый ключ»,
  папка файлов.
