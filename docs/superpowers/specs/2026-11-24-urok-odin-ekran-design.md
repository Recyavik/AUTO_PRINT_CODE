# AutoPrintCode 0.10 — один экран урока (вариант Б)

## Зачем

После 0.9 пользователь попросил разобрать программу целиком: «что глупо сделано, что правильно».
Раньше мы сохраняли идеологию Виктора «программа печатает за тебя», и пользователь с ней во многом не согласен.
Вывод разбора: **программа устроена вокруг печати, а нужна для ведения урока**. Главное окно — пульт печати.
У каждой заметки «Говоришь» есть кнопки «Печатать этот» и «Как Markdown». Редактор — анкета: 19 элементов на
заметку, 761 на урок, отсюда подлагивание. «Править»/«Готово» раздувает блок с 80 до 132 px, и всё ниже прыгает.
Урок готовят в одном виде, а ведут в другом.

Пользователь выбрал **вариант Б**: один экран урока в браузере и для подготовки, и для ведения. Окно
программы становится маленьким, печать работает в фоне. Решения отданы нам: «сделать анализ и решить
в итоге». Вопросов по ходу не задаём, только на настоящих развилках.

«Преподавателю должно быть легче, а не тяжелее» — это главный критерий для каждого решения ниже.

## Что сказал пользователь → решение

| Сказал | Решение |
|---|---|
| «Зачем мне печатать условие?», «Куда он вставляется? Только блоки с кодом должны печататься» | По Ctrl+F9 печатается **только код**. Всё остальное — для тебя, никуда не печатается и не вставляется: заметки («Говоришь», «Задание» и прочие) и картинки. Картинки можно смотреть и открывать на весь экран. Вставка картинки в Jupyter из 0.9 убирается. |
| «Удалить все задания, подготовить идеальное, чтобы я смотрел» | Один образцовый урок вместо трёх примеров. Встроенные примеры убираем, их неизменённые копии в базе удаляем. **Уроки пользователя не трогаем** (наше толкование «заданий» — примеры). |
| «Ещё 5 дальше — сколько влазит, столько и делай» | Таймер показывает столько строк, сколько помещается. «Ещё N» — только если что-то не влезло. В окне по умолчанию список виден. |
| «Дважды нажал, поредактировал, нажал Готово… почему дёргается, почему отдельно» | Правка на месте одним щелчком, тем же шрифтом, без кнопок «Править»/«Готово». Сохраняется само. Этап — строка-заголовок в ленте, а не отдельная форма. |
| «Подлагивать умудряется» | Лента рисуется браузером. Редактор кода создаётся только у блока, который правят. Страница перерисовывает только изменённые блоки. |
| «Картинку на весь экран — круто» | Остаётся. Картинку добавляют через Ctrl+V или перетаскиванием файла, без диалога «Файл…». |
| «90% выделено под автопринт, ползунки… выпадающее меню по настройкам» | Пульта больше нет. Режим, скорость, «как человек», звук и комментарии — в меню «Печать ⚙» в шапке страницы. Остальное — в окне «Настройки → Печать». |
| «Посмотри варианты» | Три варианта (А, Б, В) разобраны ниже. Выбран Б. |

## Цели, не цели, анти-цели

**Цели**
- Один экран урока со вкладками «Подготовка» и «Урок»: готовишь и ведёшь в одном и том же виде.
- Правка урока без дёрганий и задержек на уроке в 80–90 блоков.
- Ctrl+F9 никогда не печатает не то: только блоки кода и только из урока, который сейчас ведётся.
- Все 12 ошибок разбора исправлены, плюс найденные проверкой «Эфира» (раздел «Ошибки»).
- Оформление «Эфира» отдельно от расписаний, как пользователь хотел с самого начала.
- Образцовый урок, на котором видно всё.
- Сценарные тетрадки пользователя («Занятие 6»: ⏱, 🗣, ✅) превращаются в урок с этапами и плашками.

**Не цели**
- Новые способы печати. Целиком, по строкам и по шагам остаются как есть, меняется только то, где их настраивают.
- Показ слайдов ученикам на экране эфира.
- Переименование программы. Название по-прежнему в одном месте.
- Совместная правка с нескольких компьютеров.

**Анти-цели — провал, даже если «работает»**
- Заметку можно случайно напечатать ученикам.
- На экране учеников появляется что-то, о чём преподаватель не просил: подсказки, чёрный кадр, «Продолжаем» навсегда.
- Правка во время урока сбивает таймер.
- Подготовка стала сложнее, чем в 0.9: больше кликов до того же результата.
- Потеря правок: закрыл окно, пропала связь или упала программа — текст пропал.

## Ограничения

- **Окружение:** Windows 11, Python 3.14, PySide6 6.11, pygments. Новых зависимостей Python нет.
- **Страница работает без интернета.** Все скрипты и стили лежат в программе. CodeMirror 6 собирается
  заранее (esbuild) в один файл, файл кладётся в репозиторий, скрипт сборки — в `tools/`.
  Зависимости для сборки уже есть в `tests/pages/node_modules`. Лицензии MIT нужно указать.
- **Сервер слушает только 127.0.0.1.**
  - Все POST — только с заголовком `X-Suflor: 1` и со своего Origin, как сейчас `/lesson/cmd`.
  - Ограничения тела: команды и правки до 2 МБ, картинка до 25 МБ, принимаются только png/jpg/gif/webp.
  - Тип картинки проверяется по содержимому, а не по имени.
- **Данные пользователя.** templates.json и efir/*.json старых версий открываются.
  - Разовые переделки (migrations) делаются одна за другой и записываются в `settings.migrations`.
  - Перед первой переделкой 0.10 делается копия: `templates.before-0.10.json` и `efir/*.before-0.10.json`.
- **Колёсико мыши** нигде не меняет значения без щелчка, на странице тоже. Поля минут — текстовые
  с цифрами, а не `type=number`.
- **Тесты невидимы.**
  - Qt — только offscreen (`tests/quiet.py`); страница — только headless Edge (`--headless=new`).
  - Никаких настоящих щелчков мыши, окон, значка в трее и уведомлений.
  - Тесты работают со своей временной папкой данных (`AUTOPRINT_DATA`) и не на порту 8791.
- **Процессы пользователя не завершаем.** Это chrome, msedge, explorer и рабочие программы: у пользователя
  бывает прямой эфир. Окно суфлёра Edge закрываем только своё, по своему pid.
- **Текст интерфейса** — по-русски, коротко и просто, без жаргона.
- **Коммиты** — в ветку `redesign-pastetalk-ui`, отправка в форк. Версия — 0.10.0.

## Подходы

| | Суть | Плюсы | Минусы |
|---|---|---|---|
| **А** | Переделать окно Qt: спокойная шапка, правка на месте тем же шрифтом, этап — строка-заголовок | Дешевле всего | Готовишь и ведёшь по-прежнему в двух разных видах; длинный урок в Qt остаётся тяжёлым (виджет на каждый элемент) |
| **Б** ✔ | Один экран урока в браузере (страница суфлёра) с режимами «Подготовка» и «Урок»; окно программы — список уроков, нейросеть, настройки; печать — в фоне | Один вид урока; плавная лента; страница уже нравится пользователю | Самая большая переделка: редактор переезжает в браузер, протокол правок, редактор кода в браузере |
| **В** | Урок — текстовый/.md-файл, рядом живой просмотр | Быстро сделать, удобно нейросети | Минуты, роли, картинки — разметкой; голосом неудобно |

Выбран **Б**: пользователь согласился с рекомендацией.
- Страница суфлёра — лучшая часть 0.9, ей и становиться главным экраном.
- Браузер рисует длинную ленту плавно, а Qt-редактор упирается в число виджетов.

## 1. Урок: блоки двух видов

Хранение прежнее: `Template.blocks`, `Block.type` ∈ markdown | code | stage | image. Меняется смысл ролей.

**Печатается только код** (`code`). Ctrl+F9 набирает его целиком, по строкам или по шагам — как выбрано
в «Печать ⚙».

**Всё остальное — для преподавателя, не печатается и не вставляется никуда.**
- **Картинка** (`image`): слайд, скриншот, схема. Видна в ленте, по щелчку открывается на весь экран.
  Вставка картинки в Jupyter по хоткею из 0.9 (`_paste_image_block`) удаляется.
- **Заметки.** В меню роли они идут в таком порядке:

1. Говоришь (`say`) — почти дословно.
2. Расскажи (`tell`) — своими словами.
3. Спроси (`ask`) — вопрос и строки «→ ответ».
4. Делаешь (`do`) — вслух не читать.
5. Показываешь (`show`) — что видят ученики.
6. **Вывод** (`output`) — **новая роль**: что должно получиться после запуска кода. Показывается моноширинным
   шрифтом, с меткой «ВЫВОД».
7. Важно (`important`).
8. Ловушки (`trap`).
9. Для быстрых (`extra`).
10. Задание (`task`) — то, что делают ученики. Раньше называлось «Условие».
11. Заметка (`text`) — раньше «Текст».

Под «Ещё» остаются старые роли: Пояснение (`explain`) и Подсказка (`hint`). Они показываются как раньше,
но новых блоков с ними нейросеть и импорт не создают.

**Этап** (`stage`): название, минуты, вид (обычный / перерыв / зарядка), раздел (`part`) и пометка.
Всё как раньше.

**Миграция `roles_v10`**
- Поле `print_as` у markdown-блоков больше не используется. Оно остаётся в файле ради совместимости.
- Если `active_block` указывает не на код (заметку или картинку), он сбрасывается: указатель встаёт на
  первый блок кода или остаётся пустым.
- Роли существующих блоков не меняются. «Условие» просто показывается как «Задание».

## 2. Печать: что, откуда, в каком порядке

**Урок в фокусе.** Это идущий урок; если урок не идёт — тот, что открыт на экране урока.
- Ctrl+F9 и остальные хоткеи печати работают только с ним.
- Во время урока экран урока всегда показывает идущий урок.
- Открыть другой урок можно только через вопрос «Идёт урок «X». Завершить его и открыть «Y»?».

**Следующий к печати** — `Template.active_block`, всегда блок кода.
- На странице он помечен «▶ Следующим · Ctrl+F9». В плане урока у его этапа стоит маленькая метка.
- Назначить блок следующим можно тремя способами:
  - кнопкой «Следующим» на блоке кода (в обоих режимах страницы);
  - Ctrl+F12 / Ctrl+Shift+F12 — перебор блоков кода по порядку;
  - автопереходом.
- **Щелчок по заметке ничего не назначает.**
- **Автопереход.** Блок напечатан или вставлен, а в режиме «по шагам» — напечатан последний шаг: указатель
  сам переходит к следующему блоку кода. Настройка `auto_advance` удаляется: автопереход есть всегда.
- **Ctrl+F10.**
  - Во время печати или на паузе — этот блок заново.
  - После окончания — указатель возвращается на последний напечатанный блок, без печати, с сообщением
    «Ещё раз: Код 3 — Ctrl+F9».
- **Указатель в конце урока.** Ctrl+F9 сообщает «Весь код урока напечатан».

**Защита (новая ошибка E13).** Если по Ctrl+F9 впереди окно самой программы или окно экрана урока (Edge,
запущенный нами), программа не печатает. Вместо этого — сообщение «Поставьте курсор в
Jupyter (или другой редактор) и нажмите Ctrl+F9 там». Иначе код набирался бы в саму страницу.

**Где видно ход печати**
- На блоке: полоска хода и надпись «Печатается · 40% · Ctrl+F9 — пауза».
- В шапке страницы тот же короткий значок — его видно, даже если блок прокручен.
- В окне программы — строка состояния внизу.
- В трее — значок, как сейчас.

**«По строкам» и «по шагам» на странице.** У блока, который печатается следующим:
- по строкам подсвечена следующая строка;
- по шагам подсвечены строки следующего шага, а над кодом стоит «Скажи: …» — комментарии шага.

Это заменяет полосу суфлёра над лентой и отдельное окно суфлёра; их удаляем.

**Выделенные строки.** В «Подготовке» выделение в редакторе кода запоминается в `Block.sel`, как сейчас
в Qt. На блоке появляется метка «Печатается выделенное: строки 3–7 · сбросить».

**Разметка шагов.** В редакторе кода слева от номеров строк идёт полоса шагов с номером и цветом.
- Выделить строки и нажать Alt+1…9 — назначить шаг.
- Правый щелчок по полосе — меню.
- Хранится в `Block.steps`, как сейчас.

**Нажатие кнопкой с отсчётом** со страницы не делаем: фокус был бы на странице. Печать запускают Ctrl+F9
из редактора, а «Старт/пауза» в меню трея остаётся с отсчётом 3 с.

## 3. Экран урока (страница `/lesson`)

Страница одна, открывается окном Edge `--app`, как в 0.9.

### Шапка (всегда)

`[знак] Название урока ▾ · 1 ч 30 мин · 12 этапов · [Подготовка | Урок] · Печать ⚙ · ⋯ · ✓ Сохранено`

- **Название ▾** — список уроков с поиском и пункт «Новый урок». В «Подготовке» по самому названию можно
  щёлкнуть и переименовать.
- **Печать ⚙** — всплывающее окно:
  - режим: Целиком / По строкам / По шагам;
  - скорость: ползунок, символов в минуту;
  - «Как человек»;
  - «Звук клавиш»;
  - «Комментарии в коде: печатать / читать вслух» (`strip_comments`);
  - ссылка «Все настройки печати…» — открывает окно настроек программы на странице «Печать».
- **⋯**:
  - Обозначения;
  - Распечатать / PDF;
  - Экспорт: .md, .ipynb, тетрадка учеников, .json;
  - Оформление эфира для урока;
  - «Распознать сценарий» (раздел 7);
  - Удалить урок — с вопросом.
- **✓ Сохранено / Сохраняю… / Нет связи — правки ждут.**

### Режим «Урок»

Как в 0.9, плюс:
- Следующий к печати и ход печати (раздел 2).
- Последняя минута этапа — янтарным: «осталось меньше минуты».
- Кнопки:
  - «Начать урок ▾» — сейчас или в ЧЧ:ММ;
  - во время урока «Начало ЧЧ:ММ»;
  - «Этап заново с этой минуты» (раньше «Сдвинуть на сейчас»);
  - «Завершить».
- Перерыв и зарядка — кнопки на карточке этапа. Зарядку видно, только если в оформлении есть видео.
- Щелчок по заметке ничего не делает. Ссылки и картинки работают.

### Режим «Подготовка»

Та же лента, тот же шрифт, те же плашки ролей. Добавляется правка.

- **Заметка.** Щелчок по тексту — правка на месте в поле с той же гарнитурой, размером, межстрочным
  расстоянием и отступами, без сдвига (допуск ±2 px). Внутри — сырой Markdown.
  - Уход из поля или Esc — снова показ. HTML для показа даёт программа в ответ на правку,
    тот же `scenario.md_html`, чтобы Markdown разбирался в одном месте.
  - Сохранение — через 400 мс после последнего нажатия и при уходе из поля.
- **Подпись плашки** («ГОВОРИШЬ · ПОВТОРЕНИЕ»).
  - Щелчок по роли — меню ролей.
  - Щелчок по заголовку — правка заголовка.
- **Код.** Щелчок — на месте блока появляется редактор CodeMirror 6 тем же шрифтом и кеглем, с подсветкой,
  номерами строк и полосой шагов. Уход из поля — снова подсвеченный HTML.
  - Редактор создаётся только у блока, который правят; одновременно жив один.
  - В шапке блока: язык (логотип), «Следующим», ⋯. В ⋯ — язык, окно (IDE / Блокнот / Терминал =
    `Block.profile`), удалить.
- **Этап** — строка-заголовок карточки: время «0:05–0:13», название (щёлкнуть и печатать), минуты
  (цифрами), вид (значок → меню обычный / перерыв / зарядка), ⋯ (раздел, пометка, удалить этап).
  - При удалении этапа его блоки переходят к предыдущему этапу, а если его нет — в «Перед уроком».
- **План слева.**
  - Минуты правятся прямо в строке плана.
  - Итог сверху пересчитывается сразу.
  - Щелчок по названию — прокрутка к этапу.
  - Перетаскивание строки плана переносит этап со всеми его блоками. Это последнее в очереди: если
    окажется тяжело, исполнитель докладывает и откладывает.
- **«+» между блоками.** Тонкая линия появляется при наведении. Щелчок открывает палитру:
  - заметки по ролям — в порядке раздела 1;
  - Код, Картинка;
  - Этап.

  Новый блок сразу в правке. Ctrl+Enter в заметке — новая заметка той же роли ниже.
- **Перенос блока** — за ручку ⋮⋮ слева (появляется при наведении) или Alt+↑ / Alt+↓.
- **Удаление** — через ⋯ или Delete на выделенном блоке. Внизу появляется «Блок удалён · Вернуть» на 10 с.
  Ctrl+Z вне текстового поля отменяет последние изменения структуры (не меньше 20 шагов).
- **Картинки.**
  - Ctrl+V вне текстового поля — картинка из буфера становится блоком после блока в фокусе, а если
    фокуса нет — в конце текущего видимого этапа.
  - Перетаскивание файла — блок встаёт туда, куда бросили.
  - Подпись правится под картинкой.
  - Щелчок — во весь экран, в обоих режимах.
  - ⋯ — заменить (файл / буфер), удалить.

- **Новый урок** создаёт «Новый урок»: этап «Начало · 5 мин» и пустую заметку «Говоришь» в правке.
  Больше не «Задача 1» и не пустой код.

### Связь страницы с программой

- **Состояние** идёт по SSE `/events?ch=lesson`, как сейчас. Добавляются поля:
  - `lessons` — id, название, минуты, этапы, дата для списка;
  - `print` — режим, скорость, человек, звук, комментарии, состояние и ход печати, блок, шаг/строка;
  - у каждого блока сырой `text` и всё, что нужно для правки: `lang`, `steps`, `sel`, `profile`, `title`,
    `role`, у этапа `minutes`, `kind`, `part`, `note`;
  - у урока `rev`, у блока `v` — версия: число, растёт при каждом изменении блока.
- **Страница перерисовывает только блоки с новой версией.** Узлы остальных блоков остаются теми же:
  прокрутка, фокус и выделение не сбиваются.
  - Блок, который сейчас правят, не перерисовывается никогда; его текст главнее.
  - Если блок, который правят, изменили в другом месте (например, нейросетью), побеждает последняя правка.
- **POST `/lesson/edit`** — `{lesson, ops:[…]}`. Действия:
  - `set` — поля блока: `text`, `title`, `role`, `lang`, `profile`, `steps`, `sel`, `minutes`, `stage_kind`,
    `part`;
  - `insert {after, block}` — программа даёт новый `id`;
  - `delete`, `move {block, after}`, `restore {snapshot, after}` (для «Вернуть»);
  - `set_lesson {title}`.

  Изменения применяются в потоке интерфейса. Ответ ждёт применения до 3 с и возвращает новые версии и
  готовый HTML затронутых блоков — по нему страница переключается из правки в показ без мигания.
- **POST `/lesson/upload?lesson=…&after=…`** — тело — картинка. Программа делает `import_media`, создаёт
  блок-картинку и возвращает его.
- **POST `/lesson/cmd`** — к прежним добавляются:
  - `open {lesson}` и `new_lesson`;
  - `print_settings {…}`;
  - `delete_lesson`, `export {fmt}`, `recognize`, `settings {page}` — открыть окно программы.
- **Сохранение базы** — прежнее: `_save_timer` 700 мс, `.bak`.
- **Нет связи.**
  - Несохранённые правки страница держит в памяти и в `localStorage` (ключ — урок и блок).
  - Связь вернулась — правки отправляются; пока они ждут, в шапке «Нет связи — правки ждут».
  - Программа перезапустилась — правки уходят после переподключения.

### Скорость

- Урок «Занятие 6» (77 блоков) и «примеры_1.2» (87 блоков) открываются на странице меньше чем за 300 мс
  на этой машине.
- Ввод в заметку не вызывает перерисовки ленты.
- Картинки грузятся лениво.
- Редактор кода не создаётся заранее.

## 5. «Эфир»

### Оформление отдельно от расписаний

- **Оформление** (`Look`): фон, видео зарядок, экран перерыва (фон, надпись, обратный отсчёт, «когда время
  вышло», шрифт, цвета) и всё прочее, что сейчас в шаблоне относится к виду экрана.
  - Хранится в новом файле `efir/looks.json`.
- **Расписание** (`Webinar`): название, строки расписания, ссылка `look` на оформление и `break_min` —
  «перерыв по умолчанию».
  - `break_min` нужен для перерыва вне плана: строка «перерыв» в расписании (первая, если их несколько),
    иначе 10 мин.
  - `break_min` — время, поэтому живёт в расписании, а не в оформлении.
  - Хранится в новом файле `efir/schedules.json`.
- **Урок** ссылается на оформление новым полем `Template.look`. Поле `preset` остаётся как было.
- **Откат на 0.9 возможен.**
  - Старый `efir/webinars.json` 0.10 только читает при миграции и больше не пишет.
  - Поле `preset` у уроков не меняется.
  - Новые роли 0.9 покажет как обычный текст.
  - После отката 0.9 увидит «Эфир» таким, каким он был до 0.10. Уроки увидит с правками 0.10.
- **Миграция `looks_v10`.**
  - У каждого шаблона из `webinars.json` вид отделяется в оформление «Оформление · <название шаблона>».
  - Одинаковые оформления сливаются в одно.
  - Расписания записываются в `schedules.json`.
  - `Template.look` и `settings.lesson_look` заполняются по прежним `preset` / `lesson_preset`.
- **Окно «Эфир»** — две вкладки: «Расписания» и «Оформления».
  - Редактор шаблона делится на два: расписание (строки, вид, демонстрация, выбор оформления) и
    оформление (всё остальное, с «Предпросмотром»).
  - Импорт и экспорт JSON расписаний сохраняют совместимость со страницей «Повестка эфира». Поля вида
    в старом JSON при импорте создают оформление.

### Таймер: сколько влезает

- **Список.**
  - Высота строки — не меньше 24 px × масштаб.
  - Строк столько, сколько помещается по высоте.
  - Если все этапы помещаются, показываются все, без «ещё N». Строки при этом не раздуваются больше
    нынешнего предела.
  - Если не помещаются: одна прошедшая строка (если есть), текущая и дальше будущие. «Ещё N раньше» и
    «ещё N дальше» появляются только тогда, когда что-то скрыто.
- **Полоса** (широкое низкое окно): клеток столько, сколько помещается при ширине клетки от 120 px × масштаб.
  Правило выбора такое же.
- **Раскладки.** Пороги меняются так, чтобы окно по умолчанию (440×270) показывало крупное «сейчас» и
  список под ним, не меньше 3 строк. Только «сейчас», без списка, — лишь в совсем маленьком окне: ниже
  примерно 160 px по высоте или 260 px по ширине. Точные пороги — за исполнителем.
- **Тест `TimerTest.test_agenda_window` переписывается** под новое правило. Ещё два теста:
  - расписание из 13 строк в высоком окне — видны все 13, без «ещё»;
  - окно по умолчанию — список не меньше 3 строк.

## 6. Образцовый урок и примеры

**Образцовый урок — «Пример урока: функции и надёжный пароль».**
- Python, 90 минут: две половины по 45, около 12 этапов, перерыв 10 мин, зарядка 5 мин.
- В нём:
  - каждая роль хотя бы раз;
  - 5–6 блоков кода, у каждого после него «Вывод»;
  - «Для быстрых», «Ловушки», «Важно»;
  - 2–3 картинки: схема «функция: вход → проверка → ответ», вид вывода, слайд с правилами пароля.
- Тема близка обоим курсам пользователя: Python и кибербезопасность.
- **Записан файлом** `autoprint/samples/lesson-example.md` в формате урока .md, с картинками рядом.
  Загружается через `lesson_md`. Картинки рисует `tools/make_sample_images.py`; готовые картинки — в
  репозитории.
- **Добавляется один раз** (`samples_seen` — "lesson_v2").
- Текст — живой, как у пользователя в «Занятии 6»: реплики, вопросы с ответами, ловушки. Не заглушки.

**Встроенные примеры** «все возможности», «пошаговый урок» и старый «тёмная тема на сайте» больше не
добавляются. Их код (`samples.py`, `samples_lesson.py`, пример шагов в `storage.py`) удаляется.

**Миграция `samples_v10`.** Из базы удаляются уроки, совпадающие со встроенными примерами в том виде,
как программа их добавляла.
- **Что сравнивается** у блоков: `type`, `role`, `text`, `lang`, `title`, `minutes`, `stage_kind`, `part`.
- **Что не сравнивается:** `id`, `start`, `preset`, `active_block`, `zoom`, `sel`.
- **Отпечатки встроенных примеров** (хэш списка этих полей) снимаются с генераторов 0.9 до их удаления и
  записываются в код миграции.
- **Изменённые пользователем копии остаются.**

Проверено на базе пользователя:
- **Удаляются три:** [0] «тёмная тема», [1] «все возможности», [3] «пошаговый урок».
- **Остаются две:** [2] «все возможности» (пользователь превратил два кода в заметки «Подсказка») и
  [10] «пошаговый урок» (пользователь добавил картинку).

Их пользователь удалит сам, если не нужны. Наш выбор: лишняя запись в списке дешевле, чем потеря правок.

**На компьютере пользователя — всё, кроме образца** (он сказал 2026-11-24: «мои тоже уроки удалите,
просто подготовь пример»).
- Это разовое действие при установке 0.10 на этом компьютере, не код программы.
- Миграция в программе по-прежнему удаляет только точные копии примеров: другим людям чужие уроки
  не удаляются.
- Перед удалением полная копия `templates.json` и папки `media` кладётся рядом с резервной копией установки.
- После запуска в базе остаётся один урок — образцовый.

## 7. Сценарные тетрадки пользователя → урок

Новый модуль `scenario_import.py` превращает блоки, прочитанные из .ipynb или .md, в урок с этапами и
ролями. Образец формата — «Занятие 6».

**Этапы и разделы**

| В тетрадке | В уроке |
|---|---|
| Заголовок `# [эмодзи] ⏱ ЧЧ:ММ–ЧЧ:ММ · Название` | Этап: название, минуты = конец − начало |
| «перерыв» в названии | Вид этапа «перерыв» |
| «заряд» или «глаз» в названии, либо 🧘 без «перерыв» | Вид этапа «зарядка». **Не** по слову «разминка»: «Разминка, 5 вопросов» — обычный этап |
| ✍️ в заголовке этапа | Пометка этапа «задание» |
| Заголовок без ⏱ перед этапами (`# 🟦 ПЕРВАЯ ПОЛОВИНА — 45 минут`) | Раздел «Первая половина» для следующих этапов |
| `---` | Выбрасывается |

**Внутри markdown-ячейки — куски по строкам-меткам**

| Метка | Роль |
|---|---|
| `🗣 **Говоришь…:**` и следующие строки `> …` | «Говоришь». Уточнение после «Говоришь» («показывая на код») идёт в заголовок плашки |
| `✅ **Ожидаемый вывод:** …` | «Вывод» — текст из `код` или из блока ``` |
| `**Решение — показываешь…:**` | «Делаешь» |
| `⚠️` | «Важно» |
| `ℹ️` | «Заметка» |
| `❓` / «Спроси» | «Спроси» |
| Остальное | «Заметка» |

**Прочее**
- Ячейки кода остаются кодом.
- Всё до первого этапа (шапка, таблица «Как читать этот файл», служебная ячейка `set_input`) уходит
  в «Перед уроком».
- **Когда срабатывает.**
  - Само, при импорте .ipynb или .md, если в нём хотя бы два заголовка с ⏱.
  - Для уже импортированных уроков — командой «Распознать сценарий» в окне программы и на странице.
    Она создаёт **копию** «<название> (сценарий)», исходный урок не меняется.
- **Тест** — на обезличенном фрагменте в формате «Занятия 6», лежит в `tests/`. Личные файлы пользователя
  в репозиторий не кладём.

## 8. Нейросеть и формат .md

- **Подсказка нейросети** (`lesson_ai`): новая роль `output`; «Задание» вместо «Условия».
  Объяснение, что печатается только код, остальное — подсказки преподавателю. Ни слова о `print_as`.
- **Формат .md урока**: `> [!output]` в обе стороны.
- **Тетрадка учеников (.ipynb)**: только ячейки кода, без заметок, этапов и картинок.

## 11. Как проверяем

- **Python.**
  - Роли, миграции (`roles_v10`, `looks_v10`, `samples_v10`; копии перед ними).
  - Урок в фокусе, указатель и автопереход, Ctrl+F10, E13.
  - Протокол правок: каждое действие и ответ.
  - Загрузка картинки: тип по содержимому, лимит.
  - Распознавание сценария, правило дня E8, пересчёт якоря E5, раскладка таймера.
  - Разделение «Эфира».
- **Сервер.**
  - Заголовок и Origin на всех POST, лимиты тела.
  - Канал preview.
  - Экран не публикует «idle» до восстановления.
- **Страница — headless Edge через протокол отладки (CDP).** Клиент WebSocket на stdlib — в
  `tests/`. Проверяем:
  - щелчок по заметке: поле правки той же высоты (±2 px), ввод сохраняется, уход из поля показывает HTML;
  - «+» вставляет блок нужной роли;
  - вставка картинки из буфера и через upload создаёт блок;
  - эхо состояния не пересоздаёт узлы других блоков;
  - в «Уроке» щелчок по заметке ничего не назначает;
  - «Следующим» на коде назначает его;
  - минуты в плане меняют итог;
  - урок на 87 блоков открывается быстрее 300 мс;
  - нет связи — правка ждёт и уходит после переподключения.
- **Ручной прогон перед сдачей.** Образцовый урок от «Подготовки» до «Урока» в Jupyter. Делается только
  с разрешения пользователя и только когда эфир не идёт.

## Решения, принятые нами (пользователь может поправить)

1. Уточнено пользователем: на его компьютере при установке удаляются все уроки, остаётся образец (с полной
   копией). Программа сама удаляет только точные копии встроенных примеров.
2. Уточнено пользователем: печатается только код. Картинки и заметки никуда не вставляются.
3. Автопереход к следующему блоку есть всегда, настройки нет.
4. Во время урока экран урока показывает только идущий урок. Другой — через «Завершить и открыть».
5. Кнопки «Печатать с отсчётом» на странице нет. Печать — Ctrl+F9 из редактора.
6. Надпись после перерыва держится 60 с, потом экран сам возвращается к фону.
7. Правило дня для времени начала: последние 6 часов — сегодня, иначе ближайшее будущее.
8. «Распознать сценарий» делает копию урока, а не меняет исходный.
9. Образцовый урок — Python, «функции и надёжный пароль», записан файлом .md.
10. Редактор кода — CodeMirror 6, собранный в один файл. Заметки правятся в простом поле с той же
    типографикой, без визуального редактора Markdown.
11. Копии встроенных примеров, которые пользователь менял ([2] и [10]), не удаляются; удаляются только
    точные копии ([0], [1], [3]).
12. Перерыв вне плана не сдвигает расписание урока. Его длина — `break_min` расписания (для урока 10 мин).
13. Откат на 0.9 остаётся возможным: у «Эфира» новые файлы (`looks.json`, `schedules.json`), у урока новое
    поле `look`, старые `webinars.json` и `preset` не переписываются.

## Оставлено исполнителю

- Точный вид: отступы, значки, палитра «+», вид ручки переноса. Цвета — из имеющихся токенов страницы.
- Настройка CodeMirror: расширения, подсветка под токены `--t-*`.
- Формы сообщений протокола сверх перечисленного, способ ожидания ответа из потока интерфейса.
- Глубина отмены (не меньше 20) и точные пороги раскладок таймера.
- Перетаскивание этапов в плане: если тяжело — отложить и сказать.
- Разбивка `lesson.html` на файлы: модули JS отдаются как `/static/lesson/*.js`.
