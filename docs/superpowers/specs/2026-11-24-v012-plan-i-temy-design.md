# 0.12 — план урока и темы, урок через свой чат с картинками

Дата: 2026-11-24. Основа — отзыв владельца после установки 0.11 (голосом, перед своим уроком) и его выбор:
«связанный план» (вариант A из двух показанных).

## Зачем

Владелец ведёт много тем по одному плану. Пример — онлайн-урок 90 минут: приветствие, разминка, теория,
перерыв, практика, итоги. Сейчас план живёт внутри каждого урока: для каждой темы его набирают заново, а при
смене минут правят во всех уроках. Ещё нельзя вывести суфлёр «только тайминги», без заметок.

Урок через ChatGPT уже работает, но путь к нему спрятан. Нужно:
- выбрать «Сценарий урока» в разборе кода;
- скопировать промпт;
- вставить ответ.

Картинки при этом теряются: слайды без PDF выбрасываются, а фото нейросеть дать не может. Зарядку
нейросеть не предлагает.

Цели 0.12:
1. **План урока — отдельная вещь, темы к нему привязаны.** Поменяли этапы или минуты в плане — поменялись у
   всех тем по нему. Сам план можно «Начать» — это суфлёр только с таймингами.
2. **Урок через свой чат — с первого экрана импорта:**
   - выбрать план;
   - «Скопировать промпт»;
   - вставить ответ;
   - получить тему по плану со слайдами, фото и зарядкой, без ручной работы.
3. **Картинки без ручного набора:**
   - слайды подставляются из презентации — сразу или позже;
   - фото по ссылкам скачиваются в урок;
   - там, где нужна картинка, но ссылки нет, остаётся место «Нужна картинка: …» с кнопкой «Вставить».
4. **Зарядка от нейросети:** она знает, какие видео зарядок есть у учителя, ставит этап и выбирает видео.
   Видео нет — нейросеть расписывает упражнения словами.
5. **План в «Уроке» можно закрепить сбоку прямо из выпадающего плана.** Время этапов и конца урока подписано
   понятно.

**Не цели (потом, 0.13):**
- «На проектор», режим докладчика, «На экран» для текстовых блоков;
- время до звонка;
- предупреждения про анимации и видео в слайдах;
- синхронизация заметок между планом и темами — синхронизируется только структура;
- рисование картинок нейросетью;
- папки и курсы.

**Анти-цели — что считать провалом, даже если всё работает:**
- **Заметки темы пропали** после правки плана: этап убрали из плана, и его заметки исчезли.
- **Правка в одной теме тихо поменяла другие.** Правка минут внутри темы не должна молча менять другие темы.
- **Программа подвисла** при скачивании картинок, особенно во время урока.
- **Ответ нейросети открыл что-то в локальной сети:** ссылка на `http://192.168.…` или файл с компьютера.
- **Тесты показали окно** на экране пользователя.

## Модель

### Шаблон (Template)
- `kind: str = ""` — `""` урок (тема), `"plan"` — план урока.
- `plan_id: str = ""` — урок привязан к плану с этим id (только у `kind == ""`).

### Блок (Block)
- `link: str = ""` — у этапа привязанного урока: id этапа плана, который он повторяет.
- `exercise: str = ""` — у этапа-зарядки: название видео зарядки из оформления, которое включать. Пусто — первое
  видео. Не нашлось по названию — тоже первое.

Картинка-«место» — существующий блок картинки (`type == "image"`) с пустым `text`:
- `slide = N` — «Слайд N, картинки пока нет»;
- `slide = 0` и `title` — «Нужна картинка: <title>».

Новых типов блоков нет.

Старые базы читаются как есть: новые поля по умолчанию пусты.

Защита от битых ссылок:
- **При загрузке базы:** если у урока `plan_id` указывает на несуществующий план, связь снимается — `plan_id` и
  `link` этапов очищаются. Этапы остаются как были.
- **При импорте из файла** (.json, .md, ответ нейросети) связь всегда снимается. Привязка к плану —
  отдельное действие или выбор плана во вкладке импорта.

### Что синхронизируется

Из плана в тему по каждому этапу:
- `title`;
- `minutes`;
- `stage_kind`;
- `part`;
- `text` (пометка этапа);
- `exercise`.

Порядок этапов тоже как в плане. Ещё синхронизируется `look` (оформление экрана учеников): если у плана
оно задано, у всех его тем оно такое же. Так видео зарядки, выбранное в плане, находится и в теме.

Не синхронизируются:
- заметки, код и картинки темы — это содержание темы;
- содержимое плана (всё, кроме этапов: заметки, код, картинки, блоки до первого этапа) — это **заготовки**:
  они копируются в новую тему один раз, при её создании.

## Синхронизация (новый модуль `autoprint/plans.py`, без Qt)

`sync_topic(topic, plan) -> bool` — привести этапы темы к плану; `True`, если что-то поменялось.
1. Блоки до первого этапа темы («перед уроком») остаются наверху как есть.
2. Тема делится на группы «этап + его блоки до следующего этапа».
3. Новый порядок — по этапам плана:
   - есть группа темы с `link == id этапа плана` → эта группа, поля этапа берутся из плана, id блока этапа
     темы не меняется;
   - нет такой группы (этап добавили в план) → новый пустой этап со свежим id и `link`.
4. Группы темы, у которых этапа в плане больше нет (или `link` пуст), **не теряются**:
   - их блоки переносятся в конец предыдущей оставшейся группы (по порядку темы), если такой нет — в первую;
   - перед перенесёнными блоками ставится заметка роли `text`: «Из этапа «X», которого больше нет в плане».
     У этой заметки-разделителя `link` = id убранного этапа плана;
   - пустая группа (без блоков) исчезает молча.
4а. **Этап вернули в план** («Вернуть» / Ctrl+Z на странице плана — тот же id). Тогда в каждой теме блоки
   от разделителя с `link == id` до следующего разделителя или этапа возвращаются под этот этап, а
   разделитель удаляется. Так отмена действительно отменяет.
5. В плане нет ни одного этапа → у темы не остаётся этапов, все блоки идут подряд с заметками-разделителями.
   В этом случае план нельзя сохранить пустым: последний этап плана не удаляется (сообщение «В плане должен
   остаться хотя бы один этап»).

`link_topic(topic, plan) -> list[str]` — первая привязка урока к плану (ответ нейросети, «Привязать к
плану…»). Возвращает замечания.
1. Этапы темы сопоставляются этапам плана:
   - сначала по названию: без регистра, пробелов по краям, «ё» = «е»; каждое название один раз;
   - оставшиеся этапы — по порядку, i-й несопоставленный этап темы ↔ i-й несопоставленный этап плана.
2. Сопоставленным ставится `link`, теме — `plan_id`, затем `sync_topic`.
3. Этапы темы сверх плана уходят по правилу п. 4 `sync_topic`. Замечание: «Этап «X» не нашёлся в плане —
   его заметки перенесены в «Y»».
4. Этапы плана, которым не нашлось пары, появляются пустыми. Замечание: «Этап плана «Z» в ответе пустой».

`plan_from_lesson(t) -> Template` — «Сделать из этапов план»:
- новый план «План: <название урока>» с копиями этапов урока (свежие id, без заметок);
- урок привязывается к нему по порядку.

`new_topic(plan, title) -> Template` — новый урок по плану:
- перед уроком — копии блоков плана до его первого этапа; если их нет — пустая заметка «Цель урока»;
- для каждого этапа плана — этап с `link` и копии всех блоков плана под этим этапом (заметки, код, картинки;
  свежие id);
- у этапа плана без блоков — пустая заметка «Говоришь». Исключение — перерыв: под ним ничего;
- `look` — как у плана.

`unlink(topic)` — урок становится обычным: `plan_id` и `link` пусты, этапы остаются.

Где вызывается:
- **После любой правки плана** (со страницы или из программы) — `sync_topic` у каждой темы этого плана.
  Изменённые темы сохраняются, страница получает новое состояние. Если идёт урок по одной из тем, работает
  существующий `_sync_live`: текущий этап остаётся на своих часах. Это защита на всякий случай: с
  экрана урока план во время урока не открыть (см. «Во время урока»).
- **Удаление этапа на странице плана.** Если в уроках по плану под этим этапом есть блоки, сначала вопрос:
  «В уроках по этому плану (N) заметки этапа «X» переедут в «Y». Удалить этап?». Для этого в состоянии
  страницы плана есть `stage_use`: id этапа → в скольких уроках под ним есть блоки.
- **Удаление плана** спрашивает: «Удалить план «X»? Уроки по нему (3) останутся с этими этапами, но без
  связи». Затем `unlink` у всех его тем.
- **«Дублировать»:**
  - копия урока остаётся привязана к тому же плану;
  - копия плана — новый план без тем.

## Правка этапов в привязанном уроке

Этапы привязанного урока **только для чтения**. Сервер отказывает в правке (ValueError → 400, страница
показывает сообщение и откатывает изменение):
- `set` полей этапа;
- `insert` и `restore` этапа;
- `delete` этапа;
- `move_stage`.

Текст отказа: «Этапы этого урока задаёт план «X» — меняйте их в плане». Перенос заметок и кода между этапами
работает как обычно.

Страница привязанного урока:
- **Карточка этапа:**
  - минуты — текстом, не кнопкой;
  - кнопка вида этапа неактивна;
  - «⋯» этапа: «Изменить в плане «X»» (открыть план) и «Отвязать урок от плана…».
- **Боковой план:**
  - минуты без полей ввода;
  - подсказка «Этапы и минуты — из плана «X»» со ссылкой «Открыть план»;
  - перетаскивать этапы нельзя.
- **Палитра «+»:** без пункта «Этап».
- **Шапка:** под названием «по плану «X» ↗» (открывает план).

**Во время урока** по привязанной теме минуты этапов не правятся. Урок идёт по событиям: сдвигает время
«Начать этот этап сейчас». «Изменить в плане «X»» во время урока делает то же, что открытие другого урока:
спрашивает «Идёт урок «…». Завершить его и открыть «X»?».

Страница плана:
- в «Подготовке» — полоса «План урока: этапы и минуты для всех уроков по нему (N): Функции, Циклы, …».
  Названия — ссылки на уроки;
- заметки в плане — заготовки, подсказка: «Заметки плана — заготовки: попадут в новые уроки по этому плану»;
- «Начать урок» по плану — обычный ход урока, суфлёр с таймингами. Заготовки плана видны: это короткие
  напоминания. Для «чистых» таймингов план держат без заготовок.
- План остаётся планом при экспорте и импорте:
  - в .json — поле `kind`;
  - в .md — строка `kind: plan` в шапке (`---`), импорт .md её читает.

## Список уроков (окно программы)

- **Список в две группы:**
  - «Планы уроков» — сверху;
  - «Уроки» — ниже.
- **Подписи:**
  - строка плана: «План · 1 ч 30 мин · 9 этапов · уроков: 3»;
  - строка привязанного урока: «1 ч 30 мин · 9 этапов · 5 кодов · план «Онлайн 90»».
- **«Новый урок ▾»:**
  - «По плану «<план>»» — по пункту на каждый план;
  - разделитель;
  - «Пустой урок», «Школа, 45 мин», «Онлайн-занятие, 90 мин», «Пара, 2×45» — как сейчас, обычный урок без
    плана;
  - разделитель;
  - «Новый план урока ▸»: «Пустой план», «Школа, 45 мин», «Онлайн-занятие, 90 мин», «Пара, 2×45»;
  - «Из презентации…».
- **Правый щелчок по уроку:**
  - «Сделать из этапов план» — у урока с этапами без плана;
  - «Привязать к плану ▸» (список планов);
  - «Отвязать от плана» — у привязанного.
- **Правый щелчок по плану:** «Новый урок по этому плану».
- **«Из методички…» → «Урок через нейросеть».** Кнопка открывает импорт на новой вкладке.

Страница, меню уроков (название урока ▾):
- список делится на «Планы» и «Уроки»;
- «Новый урок» начинается с «По плану «X»», затем прежние шаблоны и «Новый план урока».

## План в «Уроке»: закрепить и понятное время

- **Закрепить план.** В выпадающем плане («План ▾» в строке) в шапке — кнопка «Закрепить сбоку»
  (`page_plan = "side"`). У закреплённого плана — кнопка «В строку» (`page_plan = "strip"`). Настройка в
  «Аа» остаётся.
- **Время в строке.** «конец в 8:31» → «Конец урока 8:31» (сдвиг: «· +5 мин»).
- **Время этапа** — на карточке и в плане:
  - **урок идёт** — часы «11:09–11:17»; подсказка «С 0:09 до 0:17 от начала урока»;
  - **не идёт, но задано начало** («Начать в 18:00») — часы от него;
  - **иначе** — «0:09–0:17» с подсказкой «От начала урока: с 9-й по 17-ю минуту».
  - Столбец времени в плане считается так же.

## Импорт: вкладка «Урок через нейросеть»

Вкладки окна импорта:
- «Из файла»;
- «Вставить»;
- **«Урок через нейросеть»** — новая;
- **«Код через нейросеть»** — бывшая «С помощью нейросети», без «Сценария урока».

Сохранённое `lesson_style == "scenario"` в коде считается «По шагам».

Новая вкладка, сверху вниз:
1. **Как вести.**
   - «План: [▾]» — планы пользователя и «Без плана» (минуты урока и перерыв, как сейчас).
   - «Класс / возраст: [ ]» — необязательно, например «5 класс» или «11–12 лет».
   - Выбор запоминается: `lesson_plan`, `lesson_class` в настройках.
2. **Материал (необязательно).**
   - «Из файла…» — PDF, Word, PowerPoint, текст — или поле текста.
   - Подсказка: «Можно не заполнять — приложите файл прямо в чате».
   - PDF материала сразу даёт картинки слайдов. PowerPoint — через «Подставить слайды…» при добавлении
     (см. ниже).
3. **Нейросеть.**
   - «Скопировать промпт» — всегда доступна.
   - «Составить встроенной нейросетью» — если она подключена и материал есть.
   - Подсказка: «Вставьте промпт в ChatGPT (или другой чат), приложите презентацию или методичку — ответ
     вставьте ниже».
4. **Ответ.** Поле ответа и под ним «что получится», например:
   > «Функции» — 9 этапов по плану «Онлайн 90», 34 заметки, 2 блока кода. Слайды: 12 —
   > [Подставить из презентации…] (или «из материала»). Фото по ссылкам: 3 — скачаются при добавлении.
   > Нужно вставить: 2.

   И замечания привязки к плану.

«Добавить урок»:
- **Связь:** урок привязывается к выбранному плану (`link_topic`).
- **Слайды без файла презентации** остаются «местами»: «Слайд N, картинки нет».
- **Фото по ссылкам** скачиваются в фоне (см. «Картинки»):
  - в строке состояния — «Скачиваю картинки: 2 из 5…» и ссылка «Пропустить»: урок добавляется сразу,
    недокачанные фото остаются ссылками;
  - кнопка «Добавить урок» на это время недоступна;
  - «Закрыть» отменяет и скачивание, и добавление;
  - не скачалось по сети, размеру или типу — ссылка остаётся как есть (картинка покажется из интернета),
    замечание «Не скачалось: 1»;
  - ссылка не на интернет (частный адрес, `localhost`, не `http(s)`) — блок становится местом «Нужна
    картинка: <подпись>», ссылка убирается.
- Окно программы открывает новый урок. Если идёт урок — урок только добавляется в список, как сейчас.

## Промпт (один для своего чата и встроенной нейросети)

`lesson_ai.lesson_prompt(opt, *, material="", plan=None, exercises=(), slides=None) -> str`.

Встроенная нейросеть для сценария получает тот же формат: урок в Markdown. JSON-сценарий больше не
запрашивается, но старые JSON-ответы по-прежнему разбираются. Системное сообщение — промпт без материала,
материал — отдельным сообщением, как сейчас.

Что добавляется к нынешнему промпту 0.11:
- **ЭТАПЫ ПО ПЛАНУ** (выбран план):
  > ЭТАПЫ — строго по плану учителя: эти, в этом порядке, с этими минутами; не добавляй, не убирай и не
  > переименовывай:
  > ```
  > ## Приветствие · 5 мин
  > ## Перерыв · 10 мин · перерыв
  > ## Зарядка для глаз · 3 мин · зарядка
  > …
  > ```
  > Под каждым этапом — плашки для этой темы.

  Минуты урока берутся из плана. Строка «перерыв … отдельным этапом» не пишется.
- **Класс / возраст** — подставляется, если задан. Иначе остаётся «___ (если не указан — определи по
  материалу)».
- **КАРТИНКИ:**
  - слайд или страница материала — `![Слайд N](slide:N)`;
  - фото из интернета — `![что на фото](https://…)`, только если известен точный прямой адрес картинки
    (`.jpg`, `.png`, `.webp`);
  - картинка нужна, но адреса нет — `![что должно быть на картинке](фото)`: учитель вставит её сам.
- **ЗАРЯДКА:**
  - **Есть видео в оформлении урока:** «Видео зарядок у учителя: «Гимнастика для глаз», «Разминка рук». На
    этапе-зарядке укажи видео: `## Зарядка · 3 мин · зарядка: Гимнастика для глаз`; под этапом — [!say], как
    объявить зарядку».
  - **Видео нет:** «На этапе-зарядке распиши упражнения в [!say]: что делать и сколько раз».
  - **Без плана, урок от 60 минут:** добавляется «Добавь зарядку 3–5 минут отдельным этапом». С планом
    зарядку решает план.

Где берутся видео зарядок:
- выбран план — из оформления плана (если не задано — по умолчанию);
- без плана — из оформления по умолчанию;
- для «Промпт для своего чата» на странице — из оформления урока.

Где ещё используется этот промпт:
- **Страница, «⋯ → Промпт для своего чата»** — с планом урока, если урок привязан. На странице плана —
  пункт «Промпт для нового урока по этому плану».
- **«Вставить ответ нейросети»:**
  - у привязанного урока или плана — новый урок по этому плану;
  - у урока со слайдами — как в 0.11: копия со слайдами по номерам, затем привязка, если был план.

## Формат урока (.md)

- **Строка этапа зарядки:** `## Название · 3 мин · зарядка: <видео>`. `exercise` — текст после двоеточия.
  Экспорт пишет так же.
- **Картинки:**
  - `![подпись](фото)` (также `(photo)`, `(?)`, `()`) — «Нужна картинка: подпись»;
  - `![Слайд N](slide:N)` без файла презентации — «место» слайда N, а не пропуск. Ответ чата и вставка в
    уроке со слайдами — как сейчас, но вместо «блок пропущен» остаётся место.

## Картинки

### Скачивание (`autoprint/web_images.py`, без Qt, в фоновом потоке)

`fetch_images(t, *, cancel=None, progress=None, opener=None, resolve=None) -> list[str]`:
- **Какие блоки:** картинки темы с адресом `http(s)`, не больше 40 на урок.
- **Проверки:**
  - только схемы `http` и `https`;
  - адрес хоста (и после каждого перенаправления) — не частный, не loopback, не link-local и не
    зарезервированный. `resolve` подменяется в тестах;
  - ответ `image/png | jpeg | gif | webp | bmp`, не SVG;
  - не больше 10 МБ, читается с ограничением;
  - тайм-аут 15 с;
  - User-Agent `AutoPrintCode` — без данных пользователя.
- **Результат:**
  - скачалось → `import_media` → `text` блока = ссылка на копию в data/media;
  - не скачалось → блок не меняется, замечание.

Вызывается:
- в окне импорта при «Добавить урок» — поток и сигнал в окно;
- на странице после «Вставить ответ нейросети» — поток контроллера; урок добавляется по готовности.

### Ссылки в локальную сеть не показываются

Состояние страницы (`item_state`) не отдаёт странице адрес картинки, если:
- хост — `localhost`;
- хост — буквальный частный, loopback или link-local IP;
- имя хоста оканчивается на `.local`.

Такой блок показывается местом «Нужна картинка: <подпись>». Так браузер учителя не ходит по адресам
локальной сети, откуда бы ни пришёл урок: ответ нейросети, .md, .json.

### «Места» на странице

Картинка без файла — карточка с пунктиром. Пишется «Слайд 5 — картинки нет» или «Нужна картинка: кот у
ноутбука». Кнопки:
- «Вставить картинку…» — выбор файла, заменяет место;
- Ctrl+V при выбранном месте — тоже заменяет;
- «Найти в интернете» — для «Нужна картинка»: открывает поиск картинок по подписи в обычном браузере;
- «Подставить слайды из презентации…» — для мест слайдов.

«⋯ → Подставить слайды из презентации…» есть, когда в уроке есть места слайдов:
- выбрать PDF или PPTX — PPTX через PowerPoint, как «Из презентации»;
- все места «Слайд N» получают картинки страниц N;
- не нашлось страницы — замечание «Нет слайдов: 14, 15»;
- во время эфира — тот же запрет, что у импорта презентации.

Места не печатаются и не листаются ◀ ▶. «На экран» у них нет.

## Зарядка по этапу

- **Выбор видео.** Меню вида этапа → «Зарядка — видео ученикам ▸» со списком видео оформления урока.
  Выбранное — в `exercise`. Нет видео — пункт как сейчас.
- **Кнопка.** Карточка этапа-зарядки: «Включить зарядку ученикам · Гимнастика для глаз». Команда
  `exercise {stage}` → контроллер ищет видео по названию в оформлении урока. Не нашлось — первое.
- **Состояние страницы.** В `exercises` — список названий (вместо `true`/`false`). Старое поле страница
  понимает и так: непустой список — то же, что `true`.

## Безопасность и тишина

- Скачивание — только по правилам выше. Адреса из ответа нейросети не открываются, пока не скачиваются.
- «Найти в интернете» открывает браузер только по щелчку учителя.
- Тесты:
  - сеть через подменённый `opener` и `resolve`; проверку частных адресов тест включает явно;
  - без окон — offscreen Qt, headless Edge.

## Решения, принятые за владельца (можно поменять)

1. **Синхронизируется только структура.** Заметки плана — заготовки для новых уроков. Цена ошибки: правка
   заготовки в плане не дойдёт до старых уроков.
2. **Этапы привязанного урока правятся только в плане.** Ссылка «Изменить в плане» — рядом. Цена: лишний
   переход, зато минуты не меняются тихо у всех уроков.
3. **Этап убрали из плана — заметки уроков переезжают в предыдущий этап** с заметкой-разделителем. Цена:
   разделитель надо убрать руками.
4. **Удалили план — уроки остаются с этапами, без связи.**
5. **Встроенная нейросеть для урока отвечает Markdown, как свой чат.** Один формат вместо двух. Старые
   JSON-ответы читаются.
6. **«Сценарий урока» убран из разбора кода** и переехал на свою вкладку.
7. **Фото по ссылкам скачиваются при добавлении.** Не скачалось — остаётся ссылка.
8. **Скачивание из частных сетей запрещено.**
9. **Добавлен образец плана.** Образцовый урок к нему не привязан.
10. **Время: часы, когда известно начало,** иначе «0:09–0:17» с подсказкой.
11. **Во время урока минуты привязанной темы не правятся.** Сдвиг — «Начать этот этап сейчас». Цена: нельзя
    продлить один этап только сегодня.
12. **Оформление экрана (с видео зарядок) темы берут из плана.**
13. **Удаление этапа плана спрашивает, если в уроках есть его заметки.** «Вернуть» возвращает заметки на место.
14. **Ссылки на картинки в локальную сеть не показываются** — ни при скачивании, ни на странице.
