# 0.12 «План урока и темы» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Один план урока на много тем (связанный, «суфлёр таймингов»), урок через свой чат с первого экрана импорта — со слайдами, фото, «местами» для картинок и зарядкой; план можно закрепить сбоку, время подписано понятно.

**Architecture:** План — тот же `Template` с `kind="plan"`; тема хранит `plan_id`, её этапы — `link` на этапы плана. Чистый модуль `autoprint/plans.py` приводит темы к плану (`sync_topic`) после любой правки плана. Промпт урока — один (`lesson_ai.lesson_instruction` / `lesson_prompt`) для своего чата и встроенной нейросети, ответ — урок в Markdown. Картинки по ссылкам скачивает `autoprint/web_images.py` в фоне, с проверкой адресов.

**Tech Stack:** Python 3.14, PySide6 6.11 (offscreen в тестах), страница — ES-модули без сборки (`autoprint/efir/page/lesson/*.js`), тесты — `unittest` + headless Edge через `tests/cdp.py`.

**Spec:** `docs/superpowers/specs/2026-11-24-v012-plan-i-temy-design.md`

## Review Focus

1. **Правка плана, пока идёт урок по его теме** (защита на всякий случай: с экрана урока план во время урока не открыть). Поменяли минуты этапа в плане → у темы меняются минуты, таймер «Эфира» обновляется, текущий этап остаётся на своих часах (`_sync_live`). Тест — Task 3. «Изменить в плане» во время урока спрашивает, завершить ли урок. Тест — Task 5.
2. **Тема ссылается на удалённый план** (база правлена руками, сбой между сохранениями). При загрузке связь снимается, этапы снова правятся. Тест — Task 1.
3. **Ответ нейросети не по плану:**
   - этапов больше или меньше, чем в плане;
   - названия этапов чуть другие («Разминка» вместо «Повторение»).

   Заметки не теряются, замечания понятные. Тест — Task 1 (`link_topic`) и Task 10 (вкладка).
4. **Ссылка на картинку ведёт не туда:**
   - перенаправление на `127.0.0.1` или `192.168.x.x`;
   - HTML вместо картинки;
   - больше 10 МБ.

   Картинка не скачивается, ссылка остаётся, есть замечание. Тест — Task 9.
5. **Правка этапа привязанной темы, которая уже стоит в очереди страницы** (была без связи). Сервер отвечает 400 с текстом отказа, страница показывает его и не повторяет вечно. Тест — Task 5.
6. **Видео зарядки по названию не нашлось** (переименовали в оформлении) → включается первое видео, без ошибки. Тест — Task 7.
