# AutoPrintCode 1.0 «Одно окно» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вся программа в одном своём окне со встроенным браузером Qt:
- уроки;
- новый урок по шагам;
- урок с эфирной полосой;
- маленький режим;
- эфир;
- настройки;
- листы.

Старые окна Qt, Edge-суфлёр и мини-таймер уходят. Ни одна возможность не теряется.

**Architecture:**
- **Движок не меняется:** печать, хоткеи, эфир, нейросеть, импорт, хранение.
- **Логика** главного окна переезжает в объект без виджетов `App` (`autoprint/app_core.py`).
- **Окно** — `AppWindow` (`autoprint/ui/app_window.py`): рамка `FramelessWindow`, внутри один `QWebEngineView`. Он
  грузит страницу-приложение `GET /app` с локального сервера эфира.
- **Связь:**
  - состояние — каналы SSE `lesson` (как сейчас) и новый `app`;
  - действия — `POST /app/cmd` (без ответа) и `POST /app/call` (с ответом);
  - правка урока — прежние `/lesson/edit` и `/lesson/upload`.
- **Модули текста урока** (`page/lesson/render|edit|queue|code|richtext|md|state.js`) переиспользуются. Шапка,
  полоса, меню и стили пишутся заново.

**Tech Stack:** Python 3.14, PySide6 6.11 + QtWebEngine. Страница — ES-модули без сборки. Шрифты Onest и JetBrains
Mono (woff2, OFL). Тесты — `unittest` + offscreen Qt (`tests/quiet.py`) + headless Edge (`tests/cdp.py`) + один
offscreen-тест настоящего QtWebEngine.

**Spec:** `docs/superpowers/specs/2026-11-25-v1-odno-okno-design.md`. Макеты:
https://claude.ai/artifact/H8qiTb1b3AMXS687zTsN2T (`ui.css` макета — эталон токенов и компонентов).

   «Не удалось запустить окно программы: …» с «Повторить» и «Журнал работы» — не белый экран. Тест — Task 1
   (`test_server_down_shows_message`).
2. **Масштаб 200 % и узкое окно** (маленький режим 360 px, план «Сверху» с 12 этапами, длинные названия). Нет
   горизонтальной прокрутки страницы, кнопки шапки доступны. Тест — Task 4 (`test_zoom200_no_hscroll`) и Task 12
   (`test_compact_widths`).
3. **Области перетаскивания устарели после смены масштаба или размера.** Кнопки шапки нажимаются, пустое место тянет.
   Страница пересылает `window/regions` при `resize` и смене масштаба. Тест — Task 5 (`test_regions_resent_on_zoom`).
4. **Долгая работа нейросети, а человек ушёл с экрана или закрыл окно.** Работа идёт дальше, ход виден при возврате.
   «Выход» её отменяет, урок не добавляется наполовину. Тест — Task 11 (`test_job_survives_navigation`,
   `test_quit_cancels_jobs`).
5. **Перезапуск во время идущего урока.** Открывается тот же урок, эфир восстановлен, маленький режим — если был. Тест
   — Task 17 (`test_restore_live_lesson_view`).
