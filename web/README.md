# AutoPrintCode в браузере

Та же программа для живых демонстраций кода, но интерфейс открывается в браузере.
Код печатается в любое окно Windows (Блокнот, VS Code, веб-IDE, Jupyter) с позиции курсора,
в заданном темпе и со звуком настоящей клавиатуры. Удобна для записи видеогайдов по программированию:
меньше дублей и монтажа, руки и внимание свободны для объяснения. Почему — в разделе
[«Для записи видеогайдов»](../README.md#для-записи-видеогайдов-по-программированию) основного README.

Браузер не может нажимать клавиши в других окнах, поэтому версия состоит из двух частей:

- **страница** — библиотека образцов, блоки, настройки, звук клавиш;
- **помощник** — небольшая программа на Node.js. Печатает через WinAPI (`SendInput`), держит глобальные
  хоткеи и защиту от случайных нажатий, хранит образцы. Работает только на этом компьютере:
  слушает лишь `127.0.0.1` и принимает подключения только от своей страницы.

## Запуск

Нужны Windows и [Node.js](https://nodejs.org/) 22.18 или новее.

```
web\start.bat
```

При первом запуске ставятся библиотеки и собирается страница (около минуты), затем открывается
http://127.0.0.1:8790. Помощник работает без окна консоли. Окно `start.bat` закрывается само
через секунду. Выключить помощника можно кнопкой **⏻** на странице. Если нужно видеть его
сообщения, запустите `npm start` в папке `web`.

**Чтобы не запускать `start.bat` каждый раз**, включите **Настройки → Поведение → «Запускать помощника
вместе с Windows»**. Помощник будет стартовать при входе в систему без окна, а вам останется открыть
приложение AutoPrintCode (см. ниже). `start.bat` понадобится только после обновления (`git pull`).

### Своё окно и значок в панели задач

Нажмите на странице **⇓ Установить как приложение** (Chrome или Edge). AutoPrintCode откроется
в отдельном окне со своим логотипом в панели задач. Его можно закрепить: правой кнопкой по значку,
затем «Закрепить на панели задач». Дальше `start.bat` открывает уже это окно, а не вкладку браузера.
Если открыть приложение, когда помощник выключен, окно не покажет ошибку браузера, а подскажет,
как запустить помощника. Значок на вкладке и в окне меняет цвет: синий — готов, зелёный — печать, оранжевый — пауза,
фиолетовый — отсчёт.

Если на компьютере уже есть образцы Python-версии (`data/templates.json`), при первом запуске
помощник копирует их и настройки к себе в `web/data/`. Исходные файлы не меняются. Формат файлов
у обеих версий одинаковый: образцы переносятся через экспорт и импорт `.json`.

## Работа

1. Слева выберите образец, сделайте **импорт** (`.ipynb`, `.md`, `.py`, `.json`) или перетащите файлы на список.
2. Щёлкните по блоку кода, и он станет **активным** (зелёная рамка). Если выделить строки, напечатаются только они.
3. Перейдите в целевое окно, поставьте курсор и нажмите `Ctrl+F9`. Повторное нажатие ставит на паузу,
   следующее продолжает.

Кнопка **▶ Старт** на странице сворачивает браузер, даёт 3 секунды на отсчёт и печатает в окно,
которое станет активным.

| Хоткей | Действие |
|---|---|
| `Ctrl+F9` | старт / пауза / продолжить |
| `Ctrl+F10` | начать сначала |
| `Ctrl+F11` | стоп |
| `Ctrl+F12` / `Ctrl+Shift+F12` | следующий / предыдущий блок кода |
| `Alt+↓` / `Alt+↑` на странице | следующий / предыдущий блок кода |
| `Ctrl` + колёсико на блоке | масштаб блока |

Звук играет страница, поэтому вкладку не закрывайте. Свернуть её можно. Браузер разрешает звук
после первого щелчка по странице.

Всё остальное устроено как в Python-версии: профили окна «Блокнот» и «IDE», печать без комментариев,
имитация ручного ввода с опечатками, пауза при смене окна или случайном нажатии, автопереход к
следующему блоку. Подробности — в [основном README](../README.md).

Python-версия и помощник не должны работать одновременно: они займут одни и те же хоткеи.

## Журнал

`web/data/logs/autoprint-web.log` (на странице — «Журнал работы» под списком образцов). Пишутся служебные
события: старт, пауза и её причина, целевое окно, ошибки. Набираемый текст и нажатия в журнал не попадают.

## Разработка

```
cd web
npm ci
npm run dev          # помощник без своей страницы
npm run dev:client   # страница с горячей перезагрузкой: http://localhost:5173
npm test             # тесты: совпадение с Python-версией, движок печати (без нажатий)
npm run test:ui      # сквозной тест страницы: свой помощник и данные, Chrome/Edge без окна
npm run typecheck
npm run build        # сборка страницы в web/dist
```

| Часть | Технологии |
|---|---|
| Страница | React 19, TypeScript, Vite, CodeMirror 6 (редактор JupyterLab), Web Audio |
| Помощник | Node.js (TypeScript без сборки), [koffi](https://koffi.dev/) для WinAPI, WebSocket (`ws`) |

- Движок печати работает в отдельном потоке (`server/engine-worker.ts`). Он спит через `Atomics.wait`
  с системным таймером 1 мс, поэтому темп не зависит от страницы и сети, а пауза срабатывает мгновенно.
- Хоткеи и защита от случайных нажатий живут в потоке с очередью сообщений Windows (`server/input-worker.ts`).
- Логика разбиения текста, имитации человека и удаления комментариев — порт Python-версии.
  `tests/parity.test.ts` и `tests/textprint.test.ts` сверяют её с эталонами из `autoprint/*.py`
  (пересчёт: `python tools/make_web_fixtures.py`).

Проверка печати в настоящих окнах (тестовое окно Tk и Блокнот). Во время прогона не трогайте клавиатуру
и мышь. Печать идёт только в окно с ожидаемым заголовком, в любое другое не уйдёт ни одного нажатия.

```
node tests/e2e-editors.ts tk notepad
```

Docker здесь не нужен: помощнику нужен рабочий стол Windows, а из контейнера в окна Windows печатать нельзя.
