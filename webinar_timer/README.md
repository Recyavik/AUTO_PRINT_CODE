# Таймер вебинара

Ведёт вебинар по повестке строго по часам. Перед каждой активностью программа напоминает о ней на вашем мониторе. Перерыв и зарядку для глаз она показывает зрителям на экране демонстрации.

## Для коллег: готовая программа, Python не нужен

Возьмите `INSTALL/Таймер вебинара <версия>.exe` (самораспаковывающийся архив), запустите его и выберите папку.
В распакованной папке «Таймер вебинара» запустите **«Таймер вебинара.exe»**. Ярлык на рабочем столе создаст
«Создать ярлык на рабочем столе.bat». Внутри уже есть всё: Python, библиотеки, видео, фон, шрифт, шаблоны.

Собрать дистрибутив заново (нужны Python и 7-Zip на компьютере сборки): `python tools/build_webinar_dist.py`.

## Запуск из исходников (один раз на компьютере)

1. Скопируйте папку «Таймер вебинара» целиком в любое место, например на диск D: или в «Документы».
2. Запустите **`Установка.bat`**. Нужен интернет, первая установка занимает несколько минут. Права администратора не нужны.
   - Если Python не установлен, программа установит Python 3.12 сама через winget. Если это не получится, она подскажет, где скачать Python.
   - Внутри папки создаётся окружение `.venv` с библиотекой PySide6.
   - На рабочем столе появится ярлык **«Таймер вебинара»**.
3. Запускайте таймер ярлыком или файлом **`Таймер вебинара.bat`**.

Если папку перенесли в другое место или скопировали с другого компьютера, снова запустите `Установка.bat`. Шаблоны и настройки при этом сохранятся.

## Что лежит в папке

| Папка или файл | Что это |
|---|---|
| `data/plans.json` | шаблоны вебинаров |
| `data/settings.json` | настройки: мониторы, длительность перерыва, файлы, место карточек |
| `data/logs/` | журнал работы (если что-то пошло не так, пришлите его) |
| `templates/` | шаблоны для коллег (экспорт в JSON): при первом запуске на новом компьютере таймер берёт их отсюда |
| `media/` | фон перерыва, видео гимнастики для глаз, шрифт Furore |
| `webinar/` | программа |

Все пути к файлам относительные, поэтому папка работает из любого места. Шаблоны и настройки едут вместе с папкой.

**Как поделиться шаблонами.** Нажмите «Экспорт»: по умолчанию шаблон сохранится в папку `templates/`. Если коллега начинает с чистой папки (без `data/`), таймер при первом запуске загрузит все шаблоны из `templates/`. Если своя папка `data/` у коллеги уже есть, шаблон можно добавить кнопкой «Импорт»: она тоже открывается в `templates/`.

На другом компьютере мониторы называются по-другому. Если выбранный монитор не найден, таймер берёт основной монитор для демонстрации и второй для управления. Проверьте это в **⚙ Настройки → Мониторы** кнопкой «Показать номера мониторов».

## Как пользоваться

- **Шаблоны.** У каждого вида занятий свой шаблон: время старта и активности (название, демонстрация ВКЛ/ВЫКЛ, минуты, напоминание, файл на экран). Блоки перетаскиваются мышью. Шаблон можно скопировать (**⧉ Копия**), импортировать и экспортировать в JSON. Время до перерыва и после него не больше **продолжительности урока**. Она задаётся в **⚙ Настройки** (по умолчанию 45 мин) и одна для всех шаблонов.
- **Уроки.** Занятие делится перерывами на уроки. В повестке каждый урок — своя панель с заголовком «УРОК 1 · 11:00–11:45 · 45 мин», идущий урок подсвечен. Перерывы стоят между панелями.
- **Полоса эфира сверху.** Уроки и перерывы показаны в масштабе времени, прошедшее закрашено, белая черта — «сейчас». Рядом таймер: «прошло 20:00 · осталось 1:20:00».
- **«+ Добавить урок»** в редакторе шаблона — для занятий из трёх часов и больше. Кнопка добавляет в конец перерыв и блок на всю продолжительность урока, потом его можно разбить на активности. Границы уроков в редакторе отмечены золотыми линиями, под таблицей — счётчики «1-й урок: 45/45».
- **Продолжительность урока:** академический час (45 мин), обычный (60 мин), своя (любое число минут) или без предела. Общая — в «⚙ Настройки», а в редакторе шаблона можно оставить «Как в настройках» или задать свою для этого шаблона.
- **Уроки в редакторе.** Полоса «Уроки» над таблицей: двойной щелчок по уроку — его название (оно видно в повестке и на полосе эфира), перетаскивание — поменять уроки местами целиком, со всеми блоками; перерывы остаются на местах.
- **«+ Добавить блок»** вставляет новый блок после выбранного (выбран тот, в поле которого вы стоите; он обведён); если ничего не выбрано — в конец.
- **«▶ Вести эфир».** За минуту до активности и в её начале на мониторе управления появляется карточка. Кнопки на карточке:
  - **«⏰ 1 мин»** — напомнить ещё раз через минуту;
  - **«Закрыть»**;
  - **«Далее ▶»** — показать файл активности на экране демонстрации.

  Карточку можно перетащить мышью в удобное место, и таймер его запомнит.
- **Перерыв.** На весь экран демонстрации выводится заставка «ПЕРЕРЫВ» с обратным отсчётом, когда время выходит, на ней появляется «ПРОДОЛЖАЕМ».
- **Пульт видео.** Пока видео идёт на экране демонстрации, на вашем мониторе виден пульт. Зрители его не видят. На пульте:
  - **«↺ Сначала»**, **«−10 с»**, **«+10 с»**;
  - **«❚❚ Пауза / ▶ Играть»**;
  - полоса перемотки (щелчок — сразу в это место) и время;
  - громкость и кнопка 🔊 (выключить звук);
  - **«■ Убрать»** — остановить видео и убрать его с экрана.

  Пульт можно перетащить мышью, и таймер запомнит место. В конце видео оно само уходит с экрана.
- **Пульт перерыва.** Пока на экране демонстрации заставка перерыва, у вас на мониторе пульт вместо карточки. На пульте:
  - крупный отсчёт и полоса: сколько перерыва прошло;
  - **«−1 мин»** и **«+1 мин»** — укоротить или продлить перерыв (после «ПРОДОЛЖАЕМ» «+1 мин» снова включает отсчёт);
  - **«❚❚ Пауза / ▶ Продолжить»** — отсчёт у зрителей замирает;
  - **«↺ Заново»** — начать отсчёт сначала;
  - **«■ Убрать»** — убрать заставку.

  Пульт можно перетащить; место у обоих пультов общее. Расписание эфира от этих кнопок не сдвигается.
- **В любой момент** включаются кнопки «☕ Перерыв сейчас» и «👁 Зарядка сейчас». Те же команды есть в меню значка в трее. Расписание при этом не сдвигается.
- Если закрыть окно, программа уйдёт в трей, а эфир продолжится. Выйти из программы можно через меню значка в трее.
