# Таймер вебинара

Ведёт вебинар по повестке строго по часам. Перед каждой активностью программа напоминает о ней на вашем мониторе. Перерыв и зарядку для глаз она показывает зрителям на экране демонстрации.

## Для коллег: готовая программа, Python не нужен

Запустите `INSTALL/Установка — Таймер вебинара <версия>.exe` — обычный мастер установки: папка, ярлык на рабочем
столе, «Установить». Права администратора не нужны, таймер появится в меню «Пуск» и удаляется через «Приложения».
Внутри всё: Python, библиотеки, видео, фон, шрифт, шаблоны пар (они попадут в список при первом запуске).
Обновление — установщик новой версии поверх: меняются только файлы программы, шаблоны и настройки пользователя
(папка `data`) остаются. Шаблоны пар лежат и отдельно в `INSTALL/*.json` — для «Импорт JSON» у тех, у кого таймер
уже стоит. Подробно — `INSTALL/Как установить таймер вебинара.txt`.

Собрать дистрибутив заново (нужны Python и Inno Setup 6 на компьютере сборки): `python tools/build_webinar_dist.py`.

### Обновления

В установленном таймере: **⚙ Настройки → «Обновления»** — «Проверить обновления» и «⬇ Установить» (обновление
скачивается, таймер закрывается и открывается уже новым; шаблоны и настройки остаются). Галочка «Проверять
обновления автоматически» (включена по умолчанию) — при запуске и раз в сутки таймер сам проверяет и, если вышла
новая версия, сообщает (кнопка «⬆ Обновление 1.3.0» в заголовке); ставит пользователь. Во время эфира обновление
не ставится.

Выпустить обновление: поднять `__version__` в `webinar_timer/webinar/__init__.py`, закоммитить и отправить, затем
`python tools/build_webinar_dist.py --publish --notes "Что нового"`. На GitHub появится Release `webinar-v<версия>`
с лёгким установщиком (~60 МБ: без видео, фона и шрифта — их на GitHub нет). Один раз на компьютере сборки:
`gh auth login`.

## Запуск из исходников (один раз на компьютере)

1. Скопируйте папку «Таймер вебинара» целиком в любое место, например на диск D: или в «Документы».
2. Запустите **`Установка.bat`**. Нужен интернет, первая установка занимает несколько минут. Права администратора не нужны.
   - Если Python не установлен, программа установит Python 3.12 сама через winget. Если это не получится, она подскажет, где скачать Python.
   - Внутри папки создаётся окружение `.venv` с библиотекой PySide6.
   - На рабочем столе появится ярлык **«Таймер вебинара»**.
3. Запускайте таймер ярлыком или файлом **`Таймер вебинара.bat`**.

Если папку перенесли в другое место или скопировали с другого компьютера, снова запустите `Установка.bat`. Шаблоны и настройки при этом сохранятся.

## Что лежит в папке

| Папка или файл | Что это |
|---|---|
| `data/plans.json` | шаблоны вебинаров |
| `data/settings.json` | настройки: мониторы, длительность перерыва, файлы, место карточек |
| `data/logs/` | журнал работы (если что-то пошло не так, пришлите его) |
| `templates/` | шаблоны для коллег (экспорт в JSON): при первом запуске на новом компьютере таймер берёт их отсюда |
| `media/` | фон перерыва, видео гимнастики для глаз, шрифт Furore |
| `webinar/` | программа |

Все пути к файлам относительные, поэтому папка работает из любого места. Шаблоны и настройки едут вместе с папкой.

**Как поделиться шаблонами.** Нажмите «Экспорт»: по умолчанию шаблон сохранится в папку `templates/`. Если коллега начинает с чистой папки (без `data/`), таймер при первом запуске загрузит все шаблоны из `templates/`. Если своя папка `data/` у коллеги уже есть, шаблон можно добавить кнопкой «Импорт»: она тоже открывается в `templates/`.

На другом компьютере мониторы называются по-другому. Если выбранный монитор не найден, таймер берёт основной монитор для демонстрации и второй для управления. Проверьте это в **⚙ Настройки → Мониторы** кнопкой «Показать номера мониторов».

## Как пользоваться

- **Шаблоны.** У каждого вида занятий свой шаблон: время старта и активности (название, демонстрация ВКЛ/ВЫКЛ, минуты, напоминание, файл на экран). Блоки перетаскиваются мышью. Шаблон можно скопировать (**⧉ Копия**), импортировать и экспортировать в JSON. Время до перерыва и после него не больше **продолжительности урока**. Она задаётся в **⚙ Настройки** (по умолчанию 45 мин) и одна для всех шаблонов.
- **Длина ролика в шаблоне.** У блока с видео (свой файл или у «Зарядки для глаз» — видео из настроек) в колонке «На экран» видна длина ролика. Если ролик длиннее блока, она красная, с «⚠», а рядом кнопка **⇥** — «подогнать минуты блока под ролик» (с округлением вверх; если урок уже заполнен, таймер подскажет уменьшить другой блок). Ролик всё равно играет целиком: минуты блока его не обрезают.
- **Уроки.** Занятие делится перерывами на уроки. В повестке каждый урок — своя панель с заголовком «УРОК 1 · 11:00–11:45 · 45 мин», идущий урок подсвечен. Перерывы стоят между панелями.
- **Полоса эфира сверху.** Уроки и перерывы показаны в масштабе времени, прошедшее закрашено, белая черта — «сейчас». Рядом таймер: «прошло 20:00 · осталось 1:20:00».
- **«+ Добавить урок»** в редакторе шаблона — для занятий из трёх часов и больше. Кнопка добавляет в конец перерыв и блок на всю продолжительность урока, потом его можно разбить на активности. Границы уроков в редакторе отмечены золотыми линиями, под таблицей — счётчики «1-й урок: 45/45».
- **Продолжительность урока:** академический час (45 мин), обычный (60 мин), своя (любое число минут) или без предела. Общая — в «⚙ Настройки», а в редакторе шаблона можно оставить «Как в настройках» или задать свою для этого шаблона.
- **Уроки в редакторе.** Полоса «Уроки» над таблицей: двойной щелчок по уроку — его название (оно видно в повестке и на полосе эфира), перетаскивание — поменять уроки местами целиком, со всеми блоками; перерывы остаются на местах.
- **Зафиксировать тайминг урока** — правая кнопка мыши по уроку на полосе «Уроки». Блоки урока становятся только для просмотра (замок 🔒 слева): их нельзя править, переносить и удалять, внутрь урока нельзя вставить блок. Переставлять уроки целиком можно — замок едет вместе с уроком. «Разморозить» возвращает редактирование. Фиксация сохраняется в шаблоне.
- **Минуты блока** — стрелками ▲▼ или с клавиатуры; колёсико мыши число не меняет (прокручивает таблицу — минуты не сбиваются случайно). В зафиксированном уроке поле неактивно, стрелок нет.
- Окна шаблона и настроек можно развернуть на весь экран кнопкой «Развернуть» (или двойным щелчком по заголовку) и вернуть к прежнему размеру.
- **«+ Добавить блок»** вставляет новый блок после выбранного (выбран тот, в поле которого вы стоите; он обведён); если ничего не выбрано — в конец.
- **Тема: тёмная или светлая** — кнопка ☀/🌙 в заголовке окна (или ⚙ Настройки → «Тема»). Меняется сразу, не прерывая эфир, и запоминается. Экран демонстрации (заставка перерыва, видео) от темы не зависит.
- **Пока эфир не идёт** (не включали или нажали «■ Остановить эфир»), табло стоит: «ЭФИР НЕ ИДЁТ», шаблон и общая длительность — без отсчёта, подсветки текущего блока и напоминаний.
- **Начать с любой активности.** Двойной щелчок по активности в повестке (или правая кнопка → «▶ Начать эфир с этой активности») — время старта пересчитывается так, чтобы она шла сейчас, эфир включается и сразу напоминает о ней.
- **Эфир не теряется при перезапуске.** Если таймер закрыли или перезапустили во время эфира, при следующем запуске он продолжит тот же эфир — тот же шаблон и время старта (если эфир ещё не кончился).
- **«▶ Вести эфир».** За минуту до активности и в её начале на мониторе управления появляется карточка. Кнопки на карточке:
  - сверху — что происходит: «СКОРО НАЧНЁТСЯ · через 00:59», «ИДЁТ СЕЙЧАС · осталось 02:10», «ВРЕМЯ ВЫШЛО»;
  - **«▶ Показать видео»** (или «▶ Показать картинку», «☕ Начать перерыв») — только если активности есть что показать зрителям;
  - **«⏰ Напомнить через минуту»** — спрятать и показать снова через минуту;
  - **«✓ Понятно»** — убрать напоминание.

  Карточку можно перетащить мышью в удобное место, и таймер его запомнит.

  Появление карточки сопровождает мягкий колокольчик. В **⚙ Настройки** его громкость задаётся ползунком,
  кнопка **▶ Проба** даёт его послушать, а если снять галочку «Звук напоминаний», карточки будут появляться без звука.
- **Сам таймер на экран ничего не выводит.** По расписанию он только напоминает. Перерыв, видео и картинка появляются у зрителей только по вашей кнопке, а уходят только по кнопке «■ Убрать» на пульте: ни по времени, ни от случайного щелчка или Esc. Пока заставка или видео на экране, они работают как занавес: за ними можно спокойно перелистать презентацию к нужному слайду, и зрители этого не увидят.
- **Перерыв.** По кнопке «☕ Начать перерыв» на весь экран демонстрации выводится заставка «ПЕРЕРЫВ» с обратным отсчётом. Отсчёт идёт на всю длительность перерыва с момента нажатия, даже если вы начали его раньше или позже расписания. Когда время выходит, на ней появляется крупное «ПРОДОЛЖАЕМ», а под ним — «ПЕРЕРЫВ ЗАВЕРШЁН». Цвет надписей выбирается в **⚙ Настройки → «Цвет надписей заставки»** (по умолчанию белый). От темы окна таймера заставка не зависит.
- **Пульт видео.** Пока видео идёт на экране демонстрации, на вашем мониторе виден пульт. Зрители его не видят. На пульте:
  - **«↺ Сначала»**, **«−10 с»**, **«+10 с»**;
  - **«❚❚ Пауза / ▶ Играть»**;
  - полоса перемотки (щелчок — сразу в это место) и время;
  - громкость и кнопка 🔊 (выключить звук);
  - **«■ Убрать»** — остановить видео и убрать его с экрана.

  Под полосой — **«осталось 2:50 · закончится в 11:07 · по плану до 11:05»**. Если ролик выходит за конец блока по расписанию, строка жёлтая и в конце «+2 мин»: видно, досмотреть или перемотать. На паузе время окончания сдвигается.

  Пульт можно перетащить мышью, и таймер запомнит место. В конце видео на экране остаётся последний кадр, пока вы не нажмёте «■ Убрать».
- **Пульт перерыва.** Пока на экране демонстрации заставка перерыва, у вас на мониторе пульт вместо карточки. На пульте:
  - крупный отсчёт и полоса: сколько перерыва прошло;
  - **«−1 мин»** и **«+1 мин»** — укоротить или продлить перерыв (после «ПРОДОЛЖАЕМ» «+1 мин» снова включает отсчёт);
  - **«❚❚ Пауза / ▶ Продолжить»** — отсчёт у зрителей замирает;
  - **«↺ Заново»** — начать отсчёт сначала;
  - **«■ Убрать»** — убрать заставку.

  Пульт можно перетащить; место у обоих пультов общее. Расписание эфира от этих кнопок не сдвигается.
- **В любой момент** включаются кнопки «☕ Перерыв сейчас» и «👁 Зарядка сейчас». Те же команды есть в меню значка в трее. Расписание при этом не сдвигается.
- **Экстренный занавес — «🎭 Занавес» или клавиша Scroll Lock** (работает, даже когда активен PowerPoint или окно эфира; та же команда есть в трее). Клавишу можно сменить в **⚙ Настройки → «Клавиша занавеса»**: нажмите в поле нужное сочетание (с Ctrl или Alt, либо Scroll Lock, Pause, F1–F24) или выключите её. Если что-то пошло не по плану, экран демонстрации сразу закрывается заставкой с надписью без отсчёта. Надпись задаётся в **⚙ Настройки → «Текст занавеса»** (по умолчанию «Сейчас продолжим»; на экране — заглавными, длинный текст переносится и уменьшается), рядом — «Проба (5 с)». Фон и цвет надписи берутся из настроек перерыва. Перерыв или видео под занавесом продолжаются. Убирается занавес кнопкой «■ Убрать занавес» на пульте вверху вашего монитора или снова той же клавишей.
- **Без мелькания.** Когда одно на экране демонстрации сменяется другим (зарядка → перерыв, занавес → перерыв), новое появляется раньше, чем уходит прежнее: зрители не увидят, что под заставками.
- Если закрыть окно, программа уйдёт в трей, а эфир продолжится. Выйти из программы можно через меню значка в трее.
