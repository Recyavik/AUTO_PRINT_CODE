# Файлы для таймера

Таймер берёт файлы из этой папки по относительным путям, поэтому её можно копировать вместе с программой куда угодно.

| Файл | Для чего |
|---|---|
| `Фон.jpg` | фон заставки перерыва на экране демонстрации |
| `Гимнастика для глаз.mp4` | видео для блока «Зарядка для глаз» и кнопки «👁 Зарядка сейчас» |
| `Furore.otf` | шрифт надписей «ПЕРЕРЫВ» и «ПРОДОЛЖАЕМ» (ставить в Windows не нужно) |

Если файла нет, таймер всё равно работает: перерыв покажется на встроенном фоне, а зарядка — без видео.
Другие файлы можно выбрать в «Настройках» и в редакторе шаблона. Чтобы они переезжали вместе с папкой, кладите их сюда.
