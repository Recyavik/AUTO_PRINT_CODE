> [!term]
> Функция
> Именованный блок кода, который выполняет одну задачу. Его пишут один раз и вызывают по имени сколько угодно раз.

> [!term]
> Аргумент
> Значение, которое мы передаём функции в скобках при вызове. Внутри функции оно доступно под именем параметра.

## Разбор 1: длина пароля · 8 мин
*пишем вместе*

> [!say]
> Начнём с самой простой проверки: пароль не короче восьми символов. Слово `def` объявляет функцию, в скобках — параметр.

```python title="Длина пароля"
def is_long(password):
    return len(password) >= 8


print(is_long("qwerty"))
print(is_long("Kot!2024ok"))
```

> [!output]
> ```
> False
> True
> ```

> [!trap]
> - Забыли `return` — функция вернёт `None`, и `print` напечатает `None`.
> - Забыли двоеточие после `def …(password)` — ошибка `SyntaxError` ещё до запуска.
> - Отступ внутри функции — 4 пробела; без него Python не поймёт, где тело функции.

## Разбор 2: цифры и буквы · 8 мин
*пишем вместе*

> [!tell]
> Объясни своими словами, как работает поиск в цикле: идём по символам и, как только нашли подходящий, сразу выходим через `return True`. Если цикл закончился и ничего не нашли — `return False` после цикла.

```python title="Есть ли цифры и буквы"
def has_digit(password):
    for ch in password:
        if ch.isdigit():
            return True
    return False


def has_letter(password):
    for ch in password:
        if ch.isalpha():
            return True
    return False


print(has_digit("qwerty"), has_letter("qwerty"))
print(has_digit("2024"), has_letter("2024"))
```

> [!output]
> ```
> False True
> True False
> ```

> [!do]
> Поставь `return False` внутрь цикла (на один отступ правее) и запусти — пусть ученики найдут, почему `has_digit("q1")` теперь `False`. Верни как было.

## Разбор 3: return и несколько проверок · 10 мин
*пишем вместе, демонстрация включена*

> [!term]
> return
> Оператор, который завершает функцию и отдаёт результат туда, откуда её вызвали. Всё, что ниже сработавшего `return`, уже не выполняется.

> [!say]
> Соберём наши маленькие функции в одну большую. Каждая проверка, которая не прошла, сразу возвращает ответ — дальше функция не идёт.

```python title="Проверка пароля"
def check_password(password):
    if not is_long(password):
        return "слабый: короче 8 символов"
    if not has_digit(password):
        return "слабый: нет цифр"
    if not has_letter(password):
        return "слабый: нет букв"
    return "надёжный"


for p in ["qwerty", "qwerty123", "12345678", "Kot!2024ok"]:
    print(p, "→", check_password(p))
```

> [!output]
> ```
> qwerty → слабый: короче 8 символов
> qwerty123 → надёжный
> 12345678 → слабый: нет букв
> Kot!2024ok → надёжный
> ```

> [!important]
> `qwerty123` прошёл проверку, хотя его подберут за секунды. Обязательно скажи: наша функция проверяет форму пароля, а не его угадываемость. Настоящие сервисы ещё сверяют пароль со списком утёкших.

## Разбор 4: подсказки пользователю · 10 мин
*пишем вместе*

> [!tell]
> Расскажи, почему сайты не пишут просто «пароль слабый»: пользователю нужно знать, что исправить. Поэтому функция вернёт не одну строку, а список подсказок. Пустой список — замечаний нет.

```python title="Подсказки к паролю"
def password_hints(password):
    hints = []
    if len(password) < 8:
        hints.append("сделайте пароль длиннее 8 символов")
    if not has_digit(password):
        hints.append("добавьте цифру")
    if not has_upper(password):
        hints.append("добавьте заглавную букву")
    return hints


for tip in password_hints("kotik"):
    print("•", tip)
print(password_hints("Kot!2024ok"))
```

> [!output]
> ```
> • сделайте пароль длиннее 8 символов
> • добавьте цифру
> • добавьте заглавную букву
> []
> ```

## Мини-задание 2 · 9 мин
*сами, по тетрадке*

> [!task] Задание
> Напишите функцию `strength(password)`: она считает баллы от 0 до 4 — по одному за длину, цифру, заглавную букву и знак. Выведите баллы для `"kotik"`, `"Kotik2024"` и `"Kot!2024ok"`.

> [!trap]
> - Знак удобно проверить через `not password.isalnum()` — но пробел тоже «не буква и не цифра».
> - `score += 1` внутри `if` — проверьте отступы: иначе балл добавится всегда.

> [!hint]
> Начните с `score = 0` и четырёх `if` — по одному на правило. Три проверки у вас уже есть функциями: `is_long`, `has_digit`, `has_upper`.

> [!extra]
> Для быстрых: пусть `strength` возвращает не число, а слово — «слабый», «средний» или «сильный».

```python title="Решение: баллы пароля"
def strength(password):
    score = 0
    if is_long(password):
        score += 1
    if has_digit(password):
        score += 1
    if has_upper(password):
        score += 1
    if not password.isalnum():
        score += 1
    return score


for p in ["kotik", "Kotik2024", "Kot!2024ok"]:
    print(p, strength(p), "из 4")
```

> [!output]
> ```
> kotik 0 из 4
> Kotik2024 3 из 4
> Kot!2024ok 4 из 4
> ```
