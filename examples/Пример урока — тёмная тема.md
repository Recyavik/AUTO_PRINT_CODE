## Создаём тёмную тему · 20 мин
*практика вместе*

> [!show]
> Сайт кафе на платформе — сейчас он в светлой теме.

![Сайт до: светлая тема](<Пример урока — тёмная тема_files/img-2e65a1aa4779532d.png>)

> [!say]
> Создадим класс `darkTheme`: всё, что внутри него, станет тёмным. Начнём с фона и текста.

```css title="Фон и текст"
.darkTheme {
    background-color: #121212;
    color: #fff;
}
```

> [!say]
> Шапка «ближе» к нам — её фон светлее. А ссылки и логотип сделаем тёплыми, неяркими.

```css title="Шапка и ссылки"
.darkTheme header {
    background-color: #1f1f1f;
}

.darkTheme a,
.darkTheme .logo {
    color: #fac981;
}
```

> [!say]
> Осталось научить кнопку переключать класс у `body`.

```javascript title="Переключатель"
const button = document.querySelector("#theme");

button.addEventListener("click", () => {
    document.body.classList.toggle("darkTheme");
});
```

> [!trap]
> - `classList.toggle(".darkTheme")` с точкой — не сработает: точка только в CSS
> - скрипт подключили в `<head>` без `defer` — кнопки ещё нет, `querySelector` вернёт `null`

# Практика

## Своя тёмная тема · 25 мин
*каждый сам*

> [!say]
> Теперь — ваш сайт. Добавьте кнопку в шапку и сделайте тёмную тему по трём правилам.

```html title="Кнопка в шапке"
<header>
    <div class="logo">☕ Кафе «Луна»</div>
    <button id="theme">🌙 Тёмная тема</button>
</header>
```

> [!do]
> Ходи по ребятам в демонстрации их экранов. Кто застрял на `null` — смотри «Ловушки» выше.

> [!extra]
> Запомнить выбор темы: `localStorage.setItem("theme", "dark")` и прочитать его при загрузке.
