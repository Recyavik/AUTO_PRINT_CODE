ИНСТРУМЕНТЫ 1Т — УСТАНОВКА

Программы:
  • Таймер вебинара — повестка по часам, напоминания, перерыв и зарядка для глаз на экране демонстрации;
  • AutoPrintCode — печатает код в редактор «как человек» (программа для Windows);
  • AutoPrintCode Веб — то же в браузере (помощник печати + страница).
Python, Node.js и интернет для установки не нужны. Права администратора не нужны.

УСТАНОВКА — ОДНИМ МАСТЕРОМ
1. Запустите «Установка — инструменты 1Т <дата>.exe».
   Если появится синее окно «Windows защитила ваш компьютер» (издатель неизвестен) — нажмите
   «Подробнее», затем «Выполнить в любом случае». Так Windows реагирует на программы без платной
   цифровой подписи, скачанные из интернета или мессенджера; это бывает один раз.
   Можно заранее: правая кнопка по файлу → «Свойства» → галочка «Разблокировать» → «ОК».
2. Отметьте галочками нужные программы и (если хотите) «Ярлыки на рабочем столе» → «Установить».
3. Программы появятся в меню «Пуск». Каждая ставится в свою папку и удаляется отдельно.

Можно ставить и по одной — «Установка — Таймер вебинара <версия>.exe», «Установка — AutoPrintCode <версия>.exe»,
«Установка — AutoPrintCode Веб <версия>.exe».

ТАЙМЕР ВЕБИНАРА: ПЕРВЫЙ ЗАПУСК
Откройте ⚙ Настройки и проверьте мониторы: какой показывают зрителям (демонстрация) и на какой выводить
напоминания и пульты (управление). Кнопка «Показать номера мониторов» подскажет, где какой.
Шаблоны пар при первой установке уже будут в списке. Если таймер у вас уже стоит и нужны новые версии пар —
«Импорт JSON» и файл «Вебинар 1Т (… пара).json» из этой папки (ваш шаблон не заменится — добавится копия).

ОБНОВЛЕНИЕ
Программы сами проверяют обновления на GitHub и сообщают о новой версии:
  • Таймер — ⚙ Настройки → «Обновления» → «Установить» (или кнопка «⬆ Обновление …» в заголовке);
  • AutoPrintCode — Справка → «Проверить обновления…» (или «⬆» в строке состояния);
  • AutoPrintCode Веб — полоса «Доступна версия …» на странице → «⬇ Установить».
Можно и вручную — запустить мастер или установщик новой версии поверх. Ваши шаблоны, образцы, настройки
и журнал сохраняются: обновление меняет только файлы программы.

УДАЛЕНИЕ
«Параметры» → «Приложения» → нужная программа → «Удалить». Папка data с вашими данными остаётся —
её можно удалить вручную (по умолчанию программы стоят в %LOCALAPPDATA%\Programs).

Если что-то пошло не так — пришлите журнал из папки data\logs программы.
